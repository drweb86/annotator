Screenshot Annotator 能在几秒内，把杂乱的屏幕截图变成清楚的说明。按下 Print Screen，裁出重点，做好标记，然后分享。它是开源的。截图留在这台 PC 上。无需账户。无广告。无云端。

截图始终只需一键。即使应用在后台或已最小化，Print Screen 依然可用。裁出区域，再指向、说明、隐藏、打磨。

让画面自己把话说完

- 精确指向目标位置的可自定义箭头
- 带可编辑文字的气泡标注
- 用来框出重点的备注和带边框矩形
- 可改色的荧光笔
- 用模糊和涂白遮住密码、姓名和隐私信息
- 用纵向和横向裁切去掉空白
- 复制、粘贴、导入，以及导出 PNG、JPEG 或 WebP

从屏幕上取出文字

选中区域，用内置 Windows OCR 提取文字。无需额外软件。如果你已经在用 Tesseract，也可以选用该引擎。编辑结果，复制，然后继续。

保持流畅

项目会自动保存并附带预览缩略图，昨天的缺陷报告或今天的操作说明都能立刻跳回。把图片拖进来。把完成的画面复制到剪贴板。随 Windows 启动，登录后截图功能已在等候。工作区深色、轻快，并提供 57 种语言。
