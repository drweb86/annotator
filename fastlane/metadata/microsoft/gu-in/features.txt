એપ બેકગ્રાઉન્ડમાં હોય ત્યારે પણ Print Screen અથવા એપના બટનથી કેપ્ચર કરો.
એક હલનચલનમાં જરૂરી ભાગ કાપો, પછી તરત માર્ક કરો.
કસ્ટમાઇઝ કરી શકાય તેવા તીર દોરો જે બરાબર તે જગ્યા બતાવે.
સંપાદનયોગ્ય ટેક્સ્ટ સાથે સ્પીચ-બબલ કૉલઆઉટ ઉમેરો, જે વાંચી શકાય.
નોંધ અને બોર્ડરવાળા લંબચોરસથી કોઈ પણ વિસ્તાર સમજાવો અથવા ફ્રેમ કરો.
ફરીથી રંગ બદલી શકાય તેવા હાઇલાઇટરથી અગત્યની વાત ચિહ્નિત કરો.
પાસવર્ડ, નામ અને જે શેર ન કરવું જોઈએ તે બ્લર કરો.
પસંદ કરેલો ભાગ સફેદ કરો, અથવા ફક્ત તે ટુકડો ક્લિપબોર્ડ પર કૉપિ કરો.
ખાલી ઊભી અથવા આડી પટ્ટીઓ કાપો જેથી સ્ક્રીનશોટ ટૂંકો રહે.
બિલ્ટ-ઇન Windows OCRથી પસંદગીમાંથી ટેક્સ્ટ કાઢો. વૈકલ્પિક Tesseract.
સ્ક્રીનશોટ અને આકાર કૉપિ-પેસ્ટ કરો. પ્રોજેક્ટમાં છબીઓ ડ્રેગ અને ડ્રોપ કરો.
PNG, JPEG અથવા WebP એક્સપોર્ટ કરો. પ્રોજેક્ટની બાજુમાં PNG પણ સેવ થાય છે.
પ્રોજેક્ટ પ્રિવ્યૂ થમ્બનેલ સાથે ઑટો-સેવ થાય છે, તેથી તરત પાછા જઈ શકો.
Windows સાથે શરૂ કરો, સાઇન ઇન પછી Print Screen કેપ્ચર તૈયાર રહે.
ઓપન સોર્સ. જાહેરાત નહીં, એનાલિટિક્સ નહીં, એકાઉન્ટ નહીં. સ્ક્રીનશોટ આ કમ્પ્યુટર પર જ રહે.
મોટા સ્ક્રીનશોટ માટે સ્ક્રોલબાર સાથે ઘેરું, કેન્દ્રિત વર્કસ્પેસ.
નોંધ, કૉલઆઉટ અને તીર પર ફોન્ટ, રંગ, સાઇઝ, બોલ્ડ અને ઇટાલિક ગોઠવો.
ચિત્ર વાર્તા કહે ત્યાં સુધી એનોટેશન પસંદ કરો, ખસેડો અને સંપાદિત કરો.
