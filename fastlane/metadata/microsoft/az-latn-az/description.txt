Screenshot Annotator dağınıq ekran çəkilişini saniyələr ərzində aydın izaha çevirir. Print Screen düyməsinə basın, vacib olanı kəsin, işarələyin və paylaşın. Açıq mənbəlidir. Ekran görüntüləriniz bu PC-də qalır. Hesab yoxdur. Reklam yoxdur. Bulud yoxdur.

Çəkiliş həmişə bir düymə uzaqlığındadır. Print Screen tətbiq arxa planda və ya kiçildilmiş olsa belə işləyir. Bölgəni kəsin, sonra göstərin, izah edin, gizlədin və cilalayın.

Şəklin danışmasına icazə verin

- Dəqiq yerə işarə edən fərdiləşdirilə bilən oxlar
- Redaktə oluna bilən mətnli nitq balonu çağırışları
- Vacib olanı çərçivələmək üçün qeydlər və haşiyəli düzbucaqlılar
- Rəngini dəyişə biləcəyiniz vurğulayıcı
- Parollar, adlar və şəxsi məlumat üçün bulanıqlıq və ağardılma
- Boş yeri atmaq üçün şaquli və üfüqi kəsimlər
- PNG, JPEG və ya WebP kopyalama, yapışdırma, idxal və ixrac

Mətni ekrandan çıxarın

Bir sahə seçin və daxili Windows OCR ilə mətni çıxarın. Əlavə proqram tələb olunmur. Artıq Tesseract istifadə edirsinizsə, o mühərrik də dəstəklənir. Nəticəni redaktə edin, kopyalayın və davam edin.

Axında qalın

Layihələr önizləmə kiçik şəkilləri ilə avtomatik saxlanır, beləliklə dünənki xəta hesabatına və ya bu günkü təlimata dərhal qayıda bilərsiniz. Şəkilləri sürükləyin. Bitmiş şəkli buferə kopyalayın. Windows ilə başlayın ki, daxil olduqdan sonra çəkiliş sizi gözləsin. İş sahəsi tünd, sürətli və 57 dildə mövcuddur.

Ekran görüntüləriniz sizindir

Bu, açıq mənbəli masaüstü alətdir. Annotasiya edilmiş layihələr Şəkillər qovluğunuzda yaşayır. Parametrlər bu kompüterdə qalır. Heç nə yüklənmir. Necə işlədiyini yoxlaya bilərsiniz. Xəta hesabatları, sənədləşdirmə, rəylər, dəstək biletləri və hər «buna bax» anı üçün istifadə edin.

İş ciddi qalır. Alət əyləncəli qalır. Dost pişiklər ara-sıra görünür.
