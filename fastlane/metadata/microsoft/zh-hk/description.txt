Screenshot Annotator 能在數秒內，把雜亂的螢幕截圖變成清楚的說明。按下 Print Screen，裁出重點，做好標記，然後分享。它是開源的。截圖留在這部 PC 上。無需帳戶。無廣告。無雲端。

截圖始終只需一鍵。即使應用程式在背景或已最小化，Print Screen 依然可用。裁出範圍，再指向、說明、隱藏、修飾。

讓畫面自己把話說完

- 準確指向目標位置的可自訂箭頭
- 帶可編輯文字的對話氣泡
- 用來框出重點的備註和帶邊框矩形
- 可改色的螢光筆
- 用模糊和塗白遮住密碼、姓名和私隱資料
- 用直向和橫向裁切去掉空白
- 複製、貼上、匯入，以及匯出 PNG、JPEG 或 WebP

從螢幕擷取文字

選取範圍，用內建 Windows OCR 擷取文字。無需額外軟件。如果你已經在用 Tesseract，也可以選用該引擎。編輯結果，複製，然後繼續。

保持流暢

專案會自動儲存並附帶預覽縮圖，昨天的錯誤報告或今天的操作說明都能即時跳回。把圖片拖進來。把完成的畫面複製到剪貼簿。隨 Windows 啟動，登入後截圖功能已在等候。工作區深色、輕快，並提供 57 種語言。
