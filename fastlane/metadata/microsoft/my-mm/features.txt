Print Screen သို့မဟုတ် အက်ပ်ထဲက ခလုတ်ဖြင့် ဖမ်းပါ။ အက်ပ် နောက်ခံတွင် ရှိနေလည်း ရသည်။
စိတ်ဝင်စားသော အပိုင်းကို တစ်ချက်တည်း ဖြတ်ပြီး ချက်ချင်း မှတ်ပါ။
နေရာအတိအကျကို ညွှန်သော စိတ်ကြိုက်မြားများ ဆွဲပါ။
ဖတ်ရလွယ်သော ပြင်ဆင်နိုင်သည့် စာသားပါ စကားပူဖောင်းများ ထည့်ပါ။
မှတ်စုနှင့် အနားသတ် စတုဂံများချကာ နေရာကို ရှင်းပြပါ သို့မဟုတ် ဘောင်ခတ်ပါ။
အရောင်ပြောင်းနိုင်သော မီးမောင်းတံဖြင့် အရေးကြီးသည်ကို မီးမောင်းထိုးပါ။
စကားဝှက်၊ အမည်နှင့် မမျှဝေသင့်သည်ကို မှုန်ဝါးပါ။
ရွေးထားသော နေရာကို ဖြူဖျက်ပါ၊ သို့မဟုတ် ထိုအပိုင်းကိုသာ ကလစ်ဘုတ်သို့ ကူးပါ။
နေရာလွတ် ဒေါင်လိုက် သို့မဟုတ် အလျားလိုက် အမြှောင်များကို ဖြတ်ကာ ပုံကို ကျစ်လစ်အောင်ထားပါ။
ရွေးချယ်မှုမှ စာကို Windows OCR ဖြင့် ထုတ်ပါ။ Tesseract ကိုလည်း ရွေးနိုင်သည်။
စခရင်ရှော့နှင့် ပုံသဏ္ဌာန်များကို ကူးထည့်ပါ။ ပုံများကို ပရောဂျက်ထဲ ဆွဲချပါ။
PNG၊ JPEG သို့မဟုတ် WebP ထုတ်ယူပါ။ PNG တစ်ခုကို ပရောဂျက်ဘေးတွင်လည်း သိမ်းသည်။
ပရောဂျက်များ နမူနာပုံငယ်နှင့် အလိုအလျောက် သိမ်းသဖြင့် ချက်ချင်း ပြန်နိုင်သည်။
Windows နှင့်အတူ စတင်ပြီး အကောင့်ဝင်ပြီးနောက် Print Screen အသင့်ထားပါ။
ပွင့်လင်းရင်းမြစ်။ ကြော်ငြာမရှိ၊ ခွဲခြမ်းစိတ်ဖြာမှုမရှိ၊ အကောင့်မလို။ ပုံများ ဤကွန်ပျူတာတွင် ရှိသည်။
ကြီးမားသော ပုံများအတွက် လှိမ့်ဘားပါ မှောင်ပြီး အာရုံစိုက်သော အလုပ်ခွင်။
မှတ်စု၊ စကားပူဖောင်းနှင့် မြားများ၏ ဖောင့်၊ အရောင်၊ အရွယ်၊ ထူနှင့် စောင်းကို ချိန်ပါ။
ပုံက ဇာတ်လမ်းပြောသည်အထိ မှတ်ချက်များကို ရွေး၊ ရွှေ့၊ ပြင်ပါ။
