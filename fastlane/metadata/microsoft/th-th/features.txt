กด Print Screen หรือปุ่มในแอปเพื่อจับภาพ แม้แอปจะทำงานเบื้องหลังอยู่ก็ตาม
ครอปส่วนที่สนใจได้ในครั้งเดียว แล้วใส่คำอธิบายได้ทันที
วาดลูกศรที่ปรับแต่งได้ เพื่อชี้ไปยังจุดที่ต้องการให้คนดู
เพิ่มกล่องข้อความแบบลูกโป่ง พร้อมข้อความที่แก้ไขได้และอ่านง่าย
วางโน้ตและสี่เหลี่ยมมีขอบ เพื่ออธิบายหรือครอบส่วนที่ต้องการ
ไฮไลต์สิ่งสำคัญด้วยปากกาเน้นข้อความที่เปลี่ยนสีได้
เบลอรหัสผ่าน ชื่อ และสิ่งที่ไม่ควรแชร์
ทาสีขาวทับพื้นที่ที่เลือก หรือคัดลอกเฉพาะส่วนนั้นไปยังคลิปบอร์ด
ตัดแถบว่างแนวตั้งหรือแนวนอนออก เพื่อให้ภาพหน้าจอกระชับ
ดึงข้อความจากส่วนที่เลือกด้วย Windows OCR ในตัว ใช้ Tesseract ได้ตามต้องการ
คัดลอกและวางภาพหน้าจอกับรูปทรง ลากวางรูปภาพเข้าโปรเจกต์ได้
ส่งออกเป็น PNG, JPEG หรือ WebP และมีไฟล์ PNG บันทึกไว้ข้างโปรเจกต์ด้วย
โปรเจกต์บันทึกอัตโนมัติพร้อมภาพตัวอย่าง ย้อนกลับไปทำงานต่อได้ทันที
เริ่มทำงานพร้อม Windows ให้จับภาพด้วย Print Screen พร้อมใช้หลังลงชื่อเข้าใช้
โอเพนซอร์ส ไม่มีโฆษณา ไม่มีระบบวิเคราะห์ ไม่ต้องมีบัญชี ภาพหน้าจออยู่บนเครื่องนี้
พื้นที่ทำงานโทนมืด โฟกัสง่าย มีแถบเลื่อนสำหรับภาพหน้าจอขนาดใหญ่
ปรับฟอนต์ สี ขนาด ตัวหนา และตัวเอียงของโน้ต กล่องข้อความ และลูกศร
เลือก ย้าย และแก้ไขคำอธิบาย จนกว่าภาพจะเล่าเรื่องได้ครบ
