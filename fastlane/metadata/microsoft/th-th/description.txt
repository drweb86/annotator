Screenshot Annotator เปลี่ยนภาพหน้าจอที่ยุ่งเหยิงให้เป็นคำอธิบายที่ชัดเจนในไม่กี่วินาที กด Print Screen ครอปส่วนสำคัญ ใส่เครื่องหมาย แล้วแชร์ เป็นโอเพนซอร์ส ภาพหน้าจออยู่บน PC เครื่องนี้ ไม่ต้องมีบัญชี ไม่มีโฆษณา ไม่ใช้คลาวด์

การจับภาพอยู่ใกล้แค่ปุ่มเดียว Print Screen ใช้ได้แม้แอปจะทำงานเบื้องหลังหรือถูกย่อไว้ ครอปช่วงที่ต้องการ แล้วชี้ อธิบาย ซ่อน และเก็บรายละเอียด

ให้ภาพพูดแทนคุณ

- ลูกศรปรับแต่งได้ ที่ชี้ไปยังจุดที่ต้องการ
- กล่องข้อความแบบลูกโป่ง พร้อมข้อความที่แก้ไขได้
- โน้ตและสี่เหลี่ยมมีขอบ เพื่อครอบสิ่งสำคัญ
- ปากกาเน้นข้อความที่เปลี่ยนสีได้
- เบลอและทาสีขาว เพื่อซ่อนรหัสผ่าน ชื่อ และข้อมูลส่วนตัว
- ตัดแนวตั้งและแนวนอน เพื่อเอาพื้นที่ว่างออก
- คัดลอก วาง นำเข้า และส่งออก PNG, JPEG หรือ WebP

ดึงข้อความออกจากหน้าจอ

เลือกพื้นที่แล้วดึงข้อความด้วย Windows OCR ในตัว ไม่ต้องติดตั้งซอฟต์แวร์เพิ่ม หากคุณใช้ Tesseract อยู่แล้ว ก็รองรับเอนจินนั้นด้วย แก้ไขผลลัพธ์ คัดลอก แล้วไปต่อได้เลย

ทำงานต่อเนื่องได้

โปรเจกต์บันทึกอัตโนมัติพร้อมภาพตัวอย่าง คุณจึงกลับไปที่รายงานบั๊กเมื่อวานหรือคู่มือวันนี้ได้ทันที ลากรูปเข้ามาได้ คัดลอกภาพที่เสร็จแล้วไปยังคลิปบอร์ด เริ่มทำงานพร้อม Windows เพื่อให้การจับภาพรอคุณอยู่หลังลงชื่อเข้าใช้ พื้นที่ทำงานโทนมืด เร็ว และมี 57 ภาษา

ภาพหน้าจอเป็นของคุณ

นี่คือเครื่องมือเดสก์ท็อปโอเพนซอร์ส โปรเจกต์ที่ใส่คำอธิบายแล้วอยู่ในโฟลเดอร์รูปภาพ การตั้งค่าอยู่บนเครื่องนี้ ไม่มีการอัปโหลดใดๆ คุณตรวจสอบได้ว่ามันทำงานอย่างไร ใช้กับรายงานบั๊ก เอกสาร รีวิว ตั๋วซัพพอร์ต และทุกช่วงที่อยากบอกว่า “ดูตรงนี้”

งานยังจริงจัง เครื่องมือยังสนุก แมวที่เป็นมิตรแวะมาเป็นครั้งคราว
