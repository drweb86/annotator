# গোপনীয়তা নীতি

সর্বশেষ আপডেট: ২০ সেপ্টেম্বর ২০২৬

**Screenshot Annotator** by Siarhei Kuchuk

অ্যাপ্লিকেশনের নাম: Screenshot Annotator
ডেভেলপারের নাম: Siarhei Kuchuk

সফটওয়্যারটি এই কম্পিউটারে স্ক্রিনশট ধরে, টীকা দিতে দেয় এবং OCR দিয়ে নির্বাচিত এলাকার পাঠ্য পড়তে পারে। এটি ক্লাউড অ্যাকাউন্ট তৈরি করে না। ডেভেলপার আপনার স্ক্রিনশট, প্রকল্প বা ব্যবহারের তথ্য গ্রহণ করে এমন কোনো সার্ভার চালায় না।

## ডেভেলপার যে তথ্য সংগ্রহ করেন না

অ্যাপে বিজ্ঞাপন, বিশ্লেষণ, ক্র্যাশ রিপোর্টার বা ট্র্যাকিং SDK নেই। ডেভেলপার ব্যক্তিগত তথ্য সংগ্রহ, বিক্রি বা ভাগ করেন না।

## আপনার কম্পিউটারে সংরক্ষিত তথ্য

### সেটিংস

অ্যাপ্লিকেশন সেটিংস (Print Screen হটকি, সিস্টেমের সাথে শুরু, OCR ইঞ্জিন ও ভাষা, হাইলাইটার রং, এবং লাইসেন্স বা গোপনীয়তা উইন্ডোতে শেষ নির্বাচিত ভাষা) শুধু এই কম্পিউটারে সংরক্ষিত হয়:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator`

### প্রকল্প ও ছবি

টীকাযুক্ত প্রকল্প ও প্রিভিউ ছবি ফোল্ডারে সংরক্ষিত হয়:

- Windows: `%USERPROFILE%\Pictures\ScreenshotAnnotator`
- Linux: `~/Pictures/ScreenshotAnnotator`

স্ক্রিনশট, আমদানি করা ছবি এবং টীকা পাঠ্য সেই স্থানীয় ফাইলে থাকে (কপি করলে ক্লিপবোর্ডেও)। অ্যাপ সেগুলো আপলোড করে না।

### লগ

ডায়াগনস্টিক লগ এখানে লেখা হতে পারে:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator\Logs`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator/Logs`

অ্যাপ ক্র্যাশ করলে ডেস্কটপে স্থানীয় ত্রুটি প্রতিবেদন লিখতে পারে। সেই ফাইল কোথাও পাঠানো হয় না।

সেই মানগুলো ডেভেলপারের কাছে আপলোড হয় না।

আপনার তথ্য রাখতে কোনো ডেভেলপার সার্ভার ব্যবহার হয় না।

## স্ক্রিন ধরা ও OCR

Print Screen (বা স্ক্রিনশট কমান্ড) ব্যবহার করলে অ্যাপ বর্তমান স্ক্রিন ধরে যাতে আপনি কেটে টীকা দিতে পারেন। ধরা শুধু এই ডিভাইসে হয়।

OCR স্থানীয়ভাবে চলে:

- **Windows OCR** এই PC-তে অপারেটিং সিস্টেমের `Windows.Media.Ocr` API ব্যবহার করে।
- **Tesseract** ইনস্টল থাকলে এবং PATH-এ থাকলে এই কম্পিউটারে চলে।

চেনা পাঠ্য অ্যাপে দেখানো হয় যাতে কপি বা সম্পাদনা করতে পারেন। ডেভেলপারের কাছে পাঠানো হয় না।

## নেটওয়ার্ক ব্যবহার

### আপডেট পরীক্ষা

Store-এর বাইরের বিল্ড সর্বশেষ GitHub রিলিজ চাইতে পারে:

`https://api.github.com/repos/drweb86/annotator/releases/latest`

GitHub (Microsoft) সাধারণ HTTPS অনুরোধ (IP ঠিকানা, user-agent, সময়) পায়। ডেভেলপার সেই ট্রাফিক পান না।

Microsoft Store ইনস্টল এই পরীক্ষা ব্যবহার করে না; আপডেট Store পৌঁছে দেয়।

### আপনি যে লিংক খোলেন

অ্যাপ সিস্টেম ব্রাউজারে এই পাতা খুলতে পারে। সেই সাইটের নিজস্ব গোপনীয়তা নীতি আছে:

- প্রকল্পের হোমপেজ: [github.com/drweb86/annotator](https://github.com/drweb86/annotator)
- সর্বশেষ রিলিজ: [github.com/drweb86/annotator/releases/latest](https://github.com/drweb86/annotator/releases/latest)

লাইসেন্স অ্যাপের ভিতরে দেখানো হয়। ওয়েব পাতা হিসেবে খোলা হয় না।

## অন্য স্থানীয় আচরণ

Windows বা Linux-এ সাইন ইন করলে অ্যাপ শুরু করতে পারেন। Windows-এ স্টার্টআপ এন্ট্রি (Store ইনস্টলে Microsoft Store স্টার্টআপ টাস্ক) ব্যবহার হয়। Linux-এ autostart এন্ট্রি। এটি শুধু এই অ্যাপ আপনার কম্পিউটারে চালু করে।

ঐচ্ছিক বৈশ্বিক Print Screen হটকি অ্যাপ চলাকালীন মেমোরিতে থাকে যাতে নির্বাচক খুলতে পারে।
