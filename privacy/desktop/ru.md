# Политика конфиденциальности

Последнее обновление: 20 сентября 2026 г.

**Screenshot Annotator** by Siarhei Kuchuk

Имя приложения: Screenshot Annotator
Имя разработчика: Siarhei Kuchuk

Программа делает снимки экрана на этом компьютере, позволяет их аннотировать и может распознавать текст выбранной области с помощью OCR. Она не создаёт облачные учётные записи. Разработчик не использует сервер, который получает ваши снимки, проекты или данные об использовании.

## Данные, которые разработчик не собирает

В приложении нет рекламы, аналитики, отправки отчётов о сбоях и SDK отслеживания. Разработчик не собирает, не продаёт и не передаёт персональные данные.

## Данные, хранящиеся на вашем компьютере

### Параметры

Параметры приложения (горячая клавиша Print Screen, запуск вместе с системой, движок OCR и языки, цвет маркера и последний язык в окнах «Лицензия» или «Конфиденциальность») хранятся только на этом компьютере:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator`

### Проекты и изображения

Аннотированные проекты и миниатюры хранятся в папке «Изображения»:

- Windows: `%USERPROFILE%\Pictures\ScreenshotAnnotator`
- Linux: `~/Pictures/ScreenshotAnnotator`

Снимки экрана, импортированные изображения и текст аннотаций остаются в этих локальных файлах (или в буфере обмена, если вы их копируете). Приложение их не загружает.

### Журналы

Диагностические журналы могут записываться в:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator\Logs`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator\Logs`

При сбое приложение может записать локальный отчёт об ошибке на рабочий стол. Этот файл никуда не отправляется.

Эти данные не загружаются разработчику.

Сервер разработчика не используется для хранения ваших данных.

## Захват экрана и OCR

Когда вы нажимаете Print Screen (или команду снимка), приложение захватывает текущий экран, чтобы вы могли обрезать и аннотировать его. Захват происходит только на этом устройстве.

OCR выполняется локально:

- **Windows OCR** использует API `Windows.Media.Ocr` операционной системы на этом ПК.
- **Tesseract** работает на этом компьютере, если он установлен и доступен в PATH.

Распознанный текст показывается в приложении, чтобы его можно было скопировать или изменить. Он не отправляется разработчику.

## Использование сети

### Проверка обновлений

Сборки не из Store могут запросить последний выпуск GitHub:

`https://api.github.com/repos/drweb86/annotator/releases/latest`

GitHub (Microsoft) получает обычный HTTPS-запрос (IP-адрес, user-agent, время). Разработчик этот трафик не получает.

Установки из Microsoft Store эту проверку не используют; обновления доставляет Store.

### Ссылки, которые вы открываете

Приложение может открыть эти страницы в системном браузере. У этих сайтов свои политики конфиденциальности:

- Страница проекта: [github.com/drweb86/annotator](https://github.com/drweb86/annotator)
- Последний выпуск: [github.com/drweb86/annotator/releases/latest](https://github.com/drweb86/annotator/releases/latest)

Лицензия показывается внутри приложения. Она не открывается как веб-страница.

## Другое локальное поведение

Вы можете запускать приложение при входе в Windows или Linux. В Windows используется запись автозагрузки (или задача запуска Microsoft Store для установок из Store). В Linux — запись автозапуска. Это запускает только это приложение на вашем компьютере.

Необязательная глобальная горячая клавиша Print Screen остаётся в памяти, пока приложение работает, чтобы открыть окно выбора.

## Дети

Приложение — инструмент аннотации снимков экрана. Оно не предназначено для детей младше 13 лет.

## Третьи стороны

GitHub обрабатывает проверку обновлений и открываемые страницы, как указано выше. Microsoft Store обрабатывает установки и обновления Store. Windows OCR предоставляется операционной системой. Разработчик этот трафик не получает.
