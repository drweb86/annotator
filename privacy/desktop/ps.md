# د محرمیت تګلاره

وروستی تازه کول: ۲۰ سپتمبر ۲۰۲۶

**Screenshot Annotator** by Siarhei Kuchuk

د غوښتنلیک نوم: Screenshot Annotator
د پراختیا کوونکي نوم: Siarhei Kuchuk

سافټویر په دې کمپیوټر کې سکرین شاټونه اخلي، تشریح اجازه ورکوي، او د OCR سره له ټاکل شوي سیمې متن لوستلی شي. کلاوډ حسابونه نه جوړوي. پراختیا کوونکی هغه سرور نه چلوي چې ستاسو سکرین شاټونه، پروژې یا د کارونې معلومات ترلاسه کړي.

## هغه معلومات چې پراختیا کوونکی نه راټولوي

اپلیکیشن اعلانونه، تحلیل، د سقوط راپور ورکوونکی یا د تعقیب SDK نه لري. پراختیا کوونکی شخصي معلومات نه راټولوي، نه پلوري او نه شریکوي.

## په ستاسو کمپیوټر کې خوندي شوي معلومات

### تنظیمات

د غوښتنلیک تنظیمات (د Print Screen شارټ‌کټ، له سیسټم سره پیل، د OCR انجن او ژبې، د هایلایټر رنګ، او په جواز یا محرمیت کړکۍ کې وروستۍ ټاکل شوې ژبه) یوازې په دې کمپیوټر کې ساتل کېږي:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator`

### پروژې او انځورونه

تشریح شوې پروژې او مخکتنې د انځورونو فولډر کې ساتل کېږي:

- Windows: `%USERPROFILE%\Pictures\ScreenshotAnnotator`
- Linux: `~/Pictures/ScreenshotAnnotator`

سکرین شاټونه، وارد شوي انځورونه او د تشریح متن په هغو سیمه‌ییزو فایلونو کې پاتې کېږي (که کاپي کړئ په کلپ‌بورډ کې هم). اپلیکیشن یې نه پورته کوي.

### لاګونه

تشخیصي لاګونه کېدای شي دلته ولیکل شي:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator\Logs`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator/Logs`

که اپلیکیشن سقوط وکړي، کېدای شي په ډیسک‌ټاپ کې سیمه‌ییز د تېروتنې راپور فایل ولیکي. هغه فایل هیڅ ځای ته نه استول کېږي.

هغه ارزښتونه پراختیا کوونکي ته نه پورته کېږي.

ستاسو د معلوماتو ساتلو لپاره د پراختیا کوونکي سرور نه کارول کېږي.

## د پردې نیول او OCR

کله چې Print Screen (یا د سکرین شاټ امر) وکاروئ، اپلیکیشن اوسنۍ پرده نیسي ترڅو پرې کړئ او تشریح یې کړئ. نیول یوازې په دې وسیله کې پېښېږي.

OCR په سیمه‌ییز ډول چلیږي:

- **Windows OCR** په دې PC کې د عملیاتي سیسټم `Windows.Media.Ocr` API کاروي.
- **Tesseract** که نصب وي او په PATH کې وي، په دې کمپیوټر کې چلیږي.

پېژندل شوی متن په اپلیکیشن کې ښودل کېږي ترڅو کاپي یا سمون وکړئ. پراختیا کوونکي ته نه استول کېږي.

## د شبکې کارول

### د تازه کولو چک

د Store څخه بهر جوړښتونه وروستی GitHub خپرونه غوښتنه کولی شي:

`https://api.github.com/repos/drweb86/annotator/releases/latest`

GitHub (Microsoft) عادي HTTPS غوښتنه (IP پته، user-agent، وخت) ترلاسه کوي. پراختیا کوونکی هغه ترافیک نه ترلاسه کوي.

د Microsoft Store نصبونه دا چک نه کاروي؛ تازه کول Store رسوي.

### هغه لینکونه چې تاسو یې پرانیزئ

اپلیکیشن په سیسټم براوزر کې دا پاڼې پرانیستلی شي. هغه سایټونه خپلې د محرمیت تګلارې لري:

- د پروژې کورپاڼه: [github.com/drweb86/annotator](https://github.com/drweb86/annotator)
- وروستۍ خپرونه: [github.com/drweb86/annotator/releases/latest](https://github.com/drweb86/annotator/releases/latest)

جواز د اپلیکیشن دننه ښودل کېږي. د ویب پاڼې په توګه نه پرانیستل کېږي.

## نور سیمه‌ییز چلند

کله چې په Windows یا Linux کې ننوځئ اپلیکیشن پیلولی شئ. په Windows کې د پیل ننوتنه (د Store نصبونو لپاره د Microsoft Store پیل دنده) کارول کېږي. په Linux کې د autostart ننوتنه. هغه یوازې دا اپلیکیشن ستاسو په کمپیوټر کې پیلوي.

اختیاري نړیوال Print Screen شارټ‌کټ پداسې حال کې چې اپلیکیشن روان وي په حافظه کې پاتې کېږي ترڅو ټاکونکی پرانیستلی شي.
