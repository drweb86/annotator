# ကိုယ်ရေးကိုယ်တာ မူဝါဒ

နောက်ဆုံး အပ်ဒိတ်: ၂၀ စက်တင်ဘာ ၂၀၂၆

**Screenshot Annotator** by Siarhei Kuchuk

အက်ပ်အမည်: Screenshot Annotator
ဖန်တီးသူအမည်: Siarhei Kuchuk

ဆော့ဖ်ဝဲသည် ဤကွန်ပျူတာပေါ်တွင် မျက်နှာပြင်ပုံများ ရိုက်ယူပြီး မှတ်ချက်ထည့်ခွင့်ပြုကာ OCR ဖြင့် ရွေးချယ်ဧရိယာမှ စာသား ဖတ်နိုင်သည်။ cloud အကောင့် မဖန်တီးပါ။ ဖန်တီးသူသည် သင့်မျက်နှာပြင်ပုံများ၊ ပရောဂျက်များ သို့မဟုတ် အသုံးပြုမှုဒေတာ လက်ခံသည့် ဆာဗာ မလည်ပတ်ပါ။

## ဖန်တီးသူ မစုဆောင်းသော ဒေတာ

အက်ပ်တွင် ကြော်ငြာ၊ ခွဲခြမ်းစိတ်ဖြာမှု၊ ပျက်စီးမှု အစီရင်ခံမှု သို့မဟုတ် ခြေရာခံ SDK မပါပါ။ ဖန်တီးသူသည် ကိုယ်ရေးကိုယ်တာ ဒေတာ မစုဆောင်း၊ မရောင်း၊ မမျှဝေပါ။

## သင့်ကွန်ပျူတာတွင် သိမ်းထားသော ဒေတာ

### ဆက်တင်များ

အက်ပ်ဆက်တင်များ (Print Screen ဟော့ကီး၊ စနစ်နှင့်အတူ စတင်ခြင်း၊ OCR အင်ဂျင်နှင့် ဘာသာစကားများ၊ မျဉ်းသားအရောင်၊ နှင့် လိုင်စင် သို့မဟုတ် ကိုယ်ရေးကိုယ်တာ ဝင်းဒိုးတွင် နောက်ဆုံး ရွေးထားသော ဘာသာစကား) ကို ဤကွန်ပျူတာတွင်သာ သိမ်းသည်:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator`

### ပရောဂျက်များနှင့် ပုံများ

မှတ်ချက်ထည့်ထားသော ပရောဂျက်များနှင့် အကြိုကြည့်ပုံများကို ပုံများ ဖိုလ်ဒါတွင် သိမ်းသည်:

- Windows: `%USERPROFILE%\Pictures\ScreenshotAnnotator`
- Linux: `~/Pictures/ScreenshotAnnotator`

မျက်နှာပြင်ပုံများ၊ တင်သွင်းပုံများနှင့် မှတ်ချက်စာသားသည် ထိုဒေသခံ ဖိုင်များတွင် ကျန်ရှိသည် (ကူးယူပါက ကလစ်ဘုတ်တွင်လည်း)။ အက်ပ်သည် ၎င်းတို့ကို အပ်လုဒ် မလုပ်ပါ။

### မှတ်တမ်းများ

ရောဂါရှာဖွေ မှတ်တမ်းများကို အောက်တွင် ရေးနိုင်သည်:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator\Logs`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator/Logs`

အက်ပ် ပျက်ပါက Desktop ပေါ်တွင် ဒေသခံ အမှားအစီရင်ခံ ဖိုင် ရေးနိုင်သည်။ ထိုဖိုင်ကို နေရာမပို့ပါ။

ထိုတန်ဖိုးများကို ဖန်တီးသူထံ အပ်လုဒ် မလုပ်ပါ။

သင့်ဒေတာ သိမ်းရန် ဖန်တီးသူ ဆာဗာ မသုံးပါ။

## မျက်နှာပြင် ရိုက်ယူခြင်းနှင့် OCR

Print Screen (သို့မဟုတ် မျက်နှာပြင်ပုံ အမိန့်) သုံးသောအခါ အက်ပ်သည် လက်ရှိ မျက်နှာပြင်ကို ရိုက်ယူပြီး ဖြတ်ကာ မှတ်ချက်ထည့်နိုင်သည်။ ရိုက်ယူခြင်းသည် ဤစက်တွင်သာ ဖြစ်သည်။

OCR သည် ဒေသခံတွင် လည်ပတ်သည်:

- **Windows OCR** သည် ဤ PC ပေါ်ရှိ လည်ပတ်စနစ်၏ `Windows.Media.Ocr` API များကို သုံးသည်။
- **Tesseract** ကို ထည့်သွင်းပြီး PATH တွင် ရှိပါက ဤကွန်ပျူတာတွင် လည်ပတ်သည်။

အသိအမှတ်ပြု စာသားကို အက်ပ်တွင် ပြပြီး ကူးယူ သို့မဟုတ် တည်းဖြတ်နိုင်သည်။ ဖန်တီးသူထံ မပို့ပါ။

## ကွန်ရက် အသုံးပြုမှု

### အပ်ဒိတ် စစ်ဆေးခြင်း

Store မဟုတ်သော တည်ဆောက်မှုများသည် နောက်ဆုံး GitHub ထုတ်ဝေမှု တောင်းနိုင်သည်:

`https://api.github.com/repos/drweb86/annotator/releases/latest`

GitHub (Microsoft) သည် ပုံမှန် HTTPS တောင်းဆိုမှု (IP လိပ်စာ၊ user-agent၊ အချိန်) လက်ခံသည်။ ဖန်တီးသူသည် ထိုအသွားအလာ မရပါ။

Microsoft Store တပ်ဆင်မှုများသည် ဤစစ်ဆေးမှု မသုံးပါ; အပ်ဒိတ်များကို Store ပို့ပေးသည်။

### သင် ဖွင့်သော လင့်ခ်များ

အက်ပ်သည် စနစ်ဘရောက်ဇာတွင် ဤစာမျက်နှာများကို ဖွင့်နိုင်သည်။ ထိုဆိုက်များတွင် ကိုယ်ပိုင် ကိုယ်ရေးကိုယ်တာ မူဝါဒ ရှိသည်:

- ပရောဂျက် ပင်မစာမျက်နှာ: [github.com/drweb86/annotator](https://github.com/drweb86/annotator)
- နောက်ဆုံး ထုတ်ဝေမှု: [github.com/drweb86/annotator/releases/latest](https://github.com/drweb86/annotator/releases/latest)

လိုင်စင်ကို အက်ပ်အတွင်း ပြသည်။ ဝဘ်စာမျက်နှာအဖြစ် မဖွင့်ပါ။

## အခြား ဒေသခံ အပြုအမူ

Windows သို့မဟုတ် Linux သို့ ဝင်သောအခါ အက်ပ် စတင်နိုင်သည်။ Windows တွင် စတင်မှု မှတ်တမ်း (Store တပ်ဆင်မှုများအတွက် Microsoft Store စတင်မှု တာဝန်) သုံးသည်။ Linux တွင် autostart မှတ်တမ်း။ ထိုသည် သင့်ကွန်ပျူတာတွင် ဤအက်ပ်ကိုသာ စတင်သည်။

ရွေးချယ်နိုင်သော ကမ္ဘာလုံးဆိုင်ရာ Print Screen ဟော့ကီးသည် အက်ပ် လည်ပတ်နေစဉ် မှတ်ဉာဏ်တွင် ကျန်ရှိပြီး ရွေးချယ်ကိရိယာ ဖွင့်နိုင်သည်။

## ကလေးများ

အက်ပ်သည် မျက်နှာပြင်ပုံ မှတ်ချက်ကိရိယာ ဖြစ်သည်။ အသက် ၁၃ နှစ်အောက် ကလေးများအတွက် ရည်ရွယ်ခြင်း မဟုတ်ပါ။

## တတိယပါတီများ

GitHub သည် အထက်ပါအတိုင်း အပ်ဒိတ် စစ်ဆေးမှုနှင့် သင် ဖွင့်သော စာမျက်နှာများကို စီမံသည်။ Microsoft Store သည် Store တပ်ဆင်မှုနှင့် အပ်ဒိတ်များကို စီမံသည်။ Windows OCR ကို လည်ပတ်စနစ် ပေးသည်။ ဖန်တီးသူသည် ထိုအသွားအလာ မရပါ။

## ပြောင်းလဲမှုများ

ဤမူဝါဒ၏ အပ်ဒိတ်များကို ပရောဂျက် သိုလှောင်ရာရှိ ဤဖိုင်တွင် တင်မည်။
