# Політика конфіденційності

Останнє оновлення: 20 вересня 2026 р.

**Screenshot Annotator** by Siarhei Kuchuk

Назва програми: Screenshot Annotator
Ім’я розробника: Siarhei Kuchuk

Програма робить знімки екрана на цьому комп’ютері, дає змогу їх анотувати та може розпізнавати текст вибраної області за допомогою OCR. Вона не створює хмарних облікових записів. Розробник не має сервера, який отримує ваші знімки, проєкти чи дані про використання.

## Дані, які розробник не збирає

У програмі немає реклами, аналітики, звітів про збої чи SDK відстеження. Розробник не збирає, не продає й не передає персональні дані.

## Дані, що зберігаються на вашому комп’ютері

### Параметри

Параметри програми (гаряча клавіша Print Screen, запуск разом із системою, рушій OCR і мови, колір маркера та остання мова у вікнах «Ліцензія» або «Конфіденційність») зберігаються лише на цьому комп’ютері:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator`

### Проєкти та зображення

Анотовані проєкти та мініатюри зберігаються в папці «Зображення»:

- Windows: `%USERPROFILE%\Pictures\ScreenshotAnnotator`
- Linux: `~/Pictures/ScreenshotAnnotator`

Знімки екрана, імпортовані зображення та текст анотацій залишаються в цих локальних файлах (або в буфері обміну, якщо ви їх копіюєте). Програма їх не завантажує.

### Журнали

Діагностичні журнали можуть записуватися в:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator\Logs`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator\Logs`

У разі збою програма може записати локальний звіт про помилку на Робочий стіл. Цей файл нікуди не надсилається.

Ці значення не завантажуються розробнику.

Сервер розробника не використовується для зберігання ваших даних.

## Захоплення екрана та OCR

Коли ви натискаєте Print Screen (або команду знімка), програма захоплює поточний екран, щоб ви могли обрізати й анотувати його. Захоплення відбувається лише на цьому пристрої.

OCR виконується локально:

- **Windows OCR** використовує API `Windows.Media.Ocr` операційної системи на цьому ПК.
- **Tesseract** працює на цьому комп’ютері, якщо його встановлено й він є в PATH.

Розпізнаний текст показується в програмі, щоб його можна було скопіювати або змінити. Його не надсилають розробнику.

### Перевірка оновлень

Збірки не зі Store можуть запитати останній випуск GitHub:

`https://api.github.com/repos/drweb86/annotator/releases/latest`

GitHub (Microsoft) отримує звичайний HTTPS-запит (IP-адреса, user-agent, час). Розробник цей трафік не отримує.

Встановлення з Microsoft Store цю перевірку не використовують; оновлення доставляє Store.

### Посилання, які ви відкриваєте

Програма може відкрити ці сторінки в системному браузері. У цих сайтів свої політики конфіденційності:

- Сторінка проєкту: [github.com/drweb86/annotator](https://github.com/drweb86/annotator)
- Останній випуск: [github.com/drweb86/annotator/releases/latest](https://github.com/drweb86/annotator/releases/latest)

Ліцензія показується всередині програми. Її не відкривають як вебсторінку.

## Інша локальна поведінка

Ви можете запускати програму під час входу в Windows або Linux. У Windows використовується запис автозапуску (або завдання запуску Microsoft Store для установок зі Store). У Linux — запис autostart. Це запускає лише цю програму на вашому комп’ютері.

Необов’язкова глобальна гаряча клавіша Print Screen залишається в пам’яті, поки програма працює, щоб відкрити вікно вибору.
