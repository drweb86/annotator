# गोपनीयता धोरण

शेवटचे अद्यतन: २० सप्टेंबर २०२६

**Screenshot Annotator** by Siarhei Kuchuk

अनुप्रयोगाचे नाव: Screenshot Annotator
डेव्हलपरचे नाव: Siarhei Kuchuk

सॉफ्टवेअर या संगणकावर स्क्रीनशॉट घेते, टिपणी करू देते आणि OCR ने निवडलेल्या क्षेत्रातील मजकूर वाचू शकते. ते क्लाउड खाती तयार करत नाही. डेव्हलपर तुमचे स्क्रीनशॉट, प्रकल्प किंवा वापर डेटा स्वीकारणारा सर्व्हर चालवत नाहीत.

## डेव्हलपर गोळा न करणारा डेटा

अॅपमध्ये जाहिराती, विश्लेषण, क्रॅश रिपोर्टर किंवा ट्रॅकिंग SDK नाही. डेव्हलपर वैयक्तिक डेटा गोळा, विक्री किंवा सामायिक करत नाहीत.

## तुमच्या संगणकावर साठवलेला डेटा

### सेटिंग्ज

अनुप्रयोग सेटिंग्ज (Print Screen हॉटकी, सिस्टमसह सुरुवात, OCR इंजिन आणि भाषा, हायलाइटर रंग, आणि परवाना किंवा गोपनीयता विंडोमध्ये शेवटची निवडलेली भाषा) फक्त या संगणकावर साठवल्या जातात:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator`

### प्रकल्प आणि प्रतिमा

टिपणी केलेले प्रकल्प आणि पूर्वावलोकने चित्रे फोल्डरमध्ये साठवली जातात:

- Windows: `%USERPROFILE%\Pictures\ScreenshotAnnotator`
- Linux: `~/Pictures/ScreenshotAnnotator`

स्क्रीनशॉट, आयात केलेल्या प्रतिमा आणि टिपणी मजकूर त्या स्थानिक फाइल्समध्ये राहतात (कॉपी केल्यास क्लिपबोर्डवरही). अॅप त्या अपलोड करत नाही.

### लॉग

निदान लॉग येथे लिहिले जाऊ शकतात:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator\Logs`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator/Logs`

अॅप क्रॅश झाल्यास डेस्कटॉपवर स्थानिक त्रुटी अहवाल फाइल लिहू शकते. ती फाइल कुठेही पाठवली जात नाही.

ती मूल्ये डेव्हलपरकडे अपलोड होत नाहीत.

तुमचा डेटा साठवण्यासाठी डेव्हलपर सर्व्हर वापरला जात नाही.

## स्क्रीन कॅप्चर आणि OCR

Print Screen (किंवा स्क्रीनशॉट आदेश) वापरताना अॅप सध्याची स्क्रीन कॅप्चर करते जेणेकरून तुम्ही कापून टिपणी करू शकता. कॅप्चर फक्त या डिव्हाइसवर होते.

OCR स्थानिकपणे चालते:

- **Windows OCR** या PC वर ऑपरेटिंग सिस्टमच्या `Windows.Media.Ocr` API वापरते.
- **Tesseract** स्थापित असेल आणि PATH मध्ये असेल तर या संगणकावर चालते.

ओळखलेला मजकूर अॅपमध्ये दाखवला जातो जेणेकरून कॉपी किंवा संपादन करता येईल. डेव्हलपरकडे पाठवला जात नाही.

## नेटवर्क वापर

### अद्यतन तपासणी

Store बाहेरील बिल्ड नवीनतम GitHub रिलीझ विनंती करू शकतात:

`https://api.github.com/repos/drweb86/annotator/releases/latest`

GitHub (Microsoft) सामान्य HTTPS विनंती (IP पत्ता, user-agent, वेळ) प्राप्त करते. डेव्हलपर तो ट्रॅफिक प्राप्त करत नाहीत.

Microsoft Store इंस्टॉल ही तपासणी वापरत नाहीत; अद्यतने Store देते.

### तुम्ही उघडता त्या दुवे

अॅप सिस्टम ब्राउझरमध्ये ही पृष्ठे उघडू शकते. त्या साइट्सची स्वतःची गोपनीयता धोरणे आहेत:

- प्रकल्प मुख्यपृष्ठ: [github.com/drweb86/annotator](https://github.com/drweb86/annotator)
- नवीनतम रिलीझ: [github.com/drweb86/annotator/releases/latest](https://github.com/drweb86/annotator/releases/latest)

परवाना अॅपमध्ये दाखवला जातो. वेब पृष्ठ म्हणून उघडला जात नाही.

## इतर स्थानिक वर्तन

Windows किंवा Linux मध्ये साइन इन करताना अॅप सुरू करू शकता. Windows वर स्टार्टअप नोंद (Store इंस्टॉलसाठी Microsoft Store स्टार्टअप कार्य) वापरली जाते. Linux वर autostart नोंद. ते फक्त हा अॅप तुमच्या संगणकावर सुरू करते.

पर्यायी जागतिक Print Screen हॉटकी अॅप चालू असताना मेमरीमध्ये राहते जेणेकरून निवडकर्ता उघडू शकेल.
