# គោលការណ៍ឯកជនភាព

ធ្វើបច្ចុប្បន្នភាពចុងក្រោយ៖ ២០ កញ្ញា ២០២៦

**Screenshot Annotator** by Siarhei Kuchuk

ឈ្មោះកម្មវិធី៖ Screenshot Annotator
ឈ្មោះអ្នកអភិវឌ្ឍន៍៖ Siarhei Kuchuk

កម្មវិធីនេះចាប់យករូបថតអេក្រង់នៅលើកុំព្យូទ័រនេះ អនុញ្ញាតឱ្យអ្នកចំណាំ ហើយអាចអានអត្ថបទពីតំបន់ដែលបានជ្រើសជាមួយ OCR។ វាមិនបង្កើតគណនីពពកទេ។ អ្នកអភិវឌ្ឍន៍មិនដំណើរការម៉ាស៊ីនមេដែលទទួលរូបថតអេក្រង់ គម្រោង ឬទិន្នន័យប្រើប្រាស់របស់អ្នកទេ។

## ទិន្នន័យដែលអ្នកអភិវឌ្ឍន៍មិនប្រមូល

កម្មវិធីមិនមានផ្សាយពាណិជ្ជកម្ម វិភាគ របាយការណ៍គាំង ឬ SDK តាមដានទេ។ អ្នកអភិវឌ្ឍន៍មិនប្រមូល លក់ ឬចែករំលែកទិន្នន័យផ្ទាល់ខ្លួនទេ។

## ទិន្នន័យដែលផ្ទុកនៅលើកុំព្យូទ័ររបស់អ្នក

### ការកំណត់

ការកំណត់កម្មវិធី (គ្រាប់ចុច Print Screen ការចាប់ផ្តើមជាមួយប្រព័ន្ធ ម៉ាស៊ីន OCR និងភាសា ពណ៌បន្លិច និងភាសាចុងក្រោយនៅក្នុងវិនដូអាជ្ញាបណ្ណ ឬឯកជនភាព) ត្រូវបានផ្ទុកតែនៅលើកុំព្យូទ័រនេះ៖

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator`

### គម្រោង និងរូបភាព

គម្រោងដែលបានចំណាំ និងរូបមើលជាមុន ត្រូវបានផ្ទុកក្នុងថតរូបភាព៖

- Windows: `%USERPROFILE%\Pictures\ScreenshotAnnotator`
- Linux: `~/Pictures/ScreenshotAnnotator`

រូបថតអេក្រង់ រូបភាពនាំចូល និងអត្ថបទចំណាំ នៅក្នុងឯកសារមូលដ្ឋានទាំងនោះ (ឬក្តារតម្បៀតប្រសិនបើអ្នកចម្លង)។ កម្មវិធីមិនផ្ទុកពួកវាឡើងទេ។

### កំណត់ហេតុ

កំណត់ហេតុវិនិច្ឆ័យអាចត្រូវបានសរសេរក្រោម៖

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator\Logs`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator/Logs`

ប្រសិនបើកម្មវិធីគាំង វាអាចសរសេរឯកសាររបាយការណ៍កំហុសមូលដ្ឋាននៅលើ Desktop។ ឯកសារនោះមិនត្រូវបានផ្ញើទៅណាទេ។

តម្លៃទាំងនោះមិនត្រូវបានផ្ទុកឡើងទៅអ្នកអភិវឌ្ឍន៍ទេ។

គ្មានម៉ាស៊ីនមេអ្នកអភិវឌ្ឍន៍ត្រូវបានប្រើដើម្បីផ្ទុកទិន្នន័យរបស់អ្នកទេ។

## ការចាប់យកអេក្រង់ និង OCR

នៅពេលអ្នកប្រើ Print Screen (ឬពាក្យបញ្ជារូបថតអេក្រង់) កម្មវិធីចាប់យកអេក្រង់បច្ចុប្បន្នដើម្បីឱ្យអ្នកកាត់ និងចំណាំ។ ការចាប់យកកើតឡើងនៅលើឧបករណ៍នេះតែប៉ុណ្ណោះ។

OCR ដំណើរការក្នុងតំបន់៖

- **Windows OCR** ប្រើ API `Windows.Media.Ocr` របស់ប្រព័ន្ធប្រតិបត្តិការនៅលើ PC នេះ។
- **Tesseract** ដំណើរការនៅលើកុំព្យូទ័រនេះ ប្រសិនបើបានដំឡើង និងស្ថិតក្នុង PATH។

អត្ថបទដែលស្គាល់ត្រូវបានបង្ហាញក្នុងកម្មវិធីដើម្បីឱ្យអ្នកចម្លង ឬកែ។ វាមិនត្រូវបានផ្ញើទៅអ្នកអភិវឌ្ឍន៍ទេ។

### ការពិនិត្យបច្ចុប្បន្នភាព

`https://api.github.com/repos/drweb86/annotator/releases/latest`

GitHub (Microsoft) ទទួលសំណើ HTTPS ធម្មតា (អាសយដ្ឋាន IP, user-agent, ពេលវេលា)។ អ្នកអភិវឌ្ឍន៍មិនទទួលចរាចរណ៍នោះទេ។

ការដំឡើង Microsoft Store មិនប្រើការពិនិត្យនេះទេ; Store ផ្តល់បច្ចុប្បន្នភាព។

- ទំព័រដើមគម្រោង៖ [github.com/drweb86/annotator](https://github.com/drweb86/annotator)
- ការចេញផ្សាយចុងក្រោយ៖ [github.com/drweb86/annotator/releases/latest](https://github.com/drweb86/annotator/releases/latest)

អាជ្ញាបណ្ណត្រូវបានបង្ហាញក្នុងកម្មវិធី។ វាមិនត្រូវបានបើកជាទំព័រវេបទេ។

## ឥរិយាបថមូលដ្ឋានផ្សេងទៀត

អ្នកអាចចាប់ផ្តើមកម្មវិធីនៅពេលចូល Windows ឬ Linux។ នៅ Windows វាប្រើធាតុចាប់ផ្តើម (ឬភារកិច្ចចាប់ផ្តើម Microsoft Store សម្រាប់ការដំឡើង Store)។ នៅ Linux ធាតុ autostart។ នោះបើកតែកម្មវិធីនេះនៅលើកុំព្យូទ័ររបស់អ្នក។

គ្រាប់ចុច Print Screen សកលស្រេចចិត្តនៅក្នុងអង្គចងចាំខណៈកម្មវិធីកំពុងដំណើរការ ដើម្បីបើកឧបករណ៍ជ្រើស។
