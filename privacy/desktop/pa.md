# ਪਰਦੇਦਾਰੀ ਨੀਤੀ

ਆਖਰੀ ਅੱਪਡੇਟ: 20 ਸਤੰਬਰ 2026

**Screenshot Annotator** by Siarhei Kuchuk

ਐਪਲੀਕੇਸ਼ਨ ਦਾ ਨਾਮ: Screenshot Annotator
ਡਿਵੈਲਪਰ ਦਾ ਨਾਮ: Siarhei Kuchuk

ਸਾਫਟਵੇਅਰ ਇਸ ਕੰਪਿਊਟਰ ਤੇ ਸਕ੍ਰੀਨਸ਼ਾਟ ਲੈਂਦਾ ਹੈ, ਟਿੱਪਣੀ ਕਰਨ ਦਿੰਦਾ ਹੈ, ਅਤੇ OCR ਨਾਲ ਚੁਣੇ ਖੇਤਰ ਤੋਂ ਲਿਖਤ ਪੜ੍ਹ ਸਕਦਾ ਹੈ। ਇਹ ਕਲਾਉਡ ਖਾਤੇ ਨਹੀਂ ਬਣਾਉਂਦਾ। ਡਿਵੈਲਪਰ ਤੁਹਾਡੇ ਸਕ੍ਰੀਨਸ਼ਾਟ, ਪ੍ਰੋਜੈਕਟ ਜਾਂ ਵਰਤੋਂ ਡਾਟਾ ਲੈਣ ਵਾਲਾ ਸਰਵਰ ਨਹੀਂ ਚਲਾਉਂਦਾ।

## ਡਾਟਾ ਜੋ ਡਿਵੈਲਪਰ ਇਕੱਠਾ ਨਹੀਂ ਕਰਦਾ

ਐਪ ਵਿੱਚ ਇਸ਼ਤਿਹਾਰ, ਵਿਸ਼ਲੇਸ਼ਣ, ਕਰੈਸ਼ ਰਿਪੋਰਟਰ ਜਾਂ ਟ੍ਰੈਕਿੰਗ SDK ਨਹੀਂ ਹੈ। ਡਿਵੈਲਪਰ ਨਿੱਜੀ ਡਾਟਾ ਇਕੱਠਾ, ਵੇਚਦਾ ਜਾਂ ਸਾਂਝਾ ਨਹੀਂ ਕਰਦਾ।

## ਤੁਹਾਡੇ ਕੰਪਿਊਟਰ ਤੇ ਸੰਭਾਲਿਆ ਡਾਟਾ

### ਸੈਟਿੰਗਾਂ

ਐਪਲੀਕੇਸ਼ਨ ਸੈਟਿੰਗਾਂ (Print Screen ਹਾਟਕੀ, ਸਿਸਟਮ ਨਾਲ ਸ਼ੁਰੂ, OCR ਇੰਜਣ ਅਤੇ ਭਾਸ਼ਾਵਾਂ, ਹਾਈਲਾਈਟਰ ਰੰਗ, ਅਤੇ ਲਾਇਸੈਂਸ ਜਾਂ ਪਰਦੇਦਾਰੀ ਵਿੰਡੋ ਵਿੱਚ ਆਖਰੀ ਚੁਣੀ ਭਾਸ਼ਾ) ਸਿਰਫ ਇਸ ਕੰਪਿਊਟਰ ਤੇ ਸੰਭਾਲੀਆਂ ਜਾਂਦੀਆਂ ਹਨ:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator`

### ਪ੍ਰੋਜੈਕਟ ਅਤੇ ਚਿੱਤਰ

ਟਿੱਪਣੀ ਵਾਲੇ ਪ੍ਰੋਜੈਕਟ ਅਤੇ ਪੂਰਵਦਰਸ਼ਨ ਤਸਵੀਰਾਂ ਫੋਲਡਰ ਵਿੱਚ ਸੰਭਾਲੇ ਜਾਂਦੇ ਹਨ:

- Windows: `%USERPROFILE%\Pictures\ScreenshotAnnotator`
- Linux: `~/Pictures/ScreenshotAnnotator`

ਸਕ੍ਰੀਨਸ਼ਾਟ, ਆਯਾਤ ਚਿੱਤਰ ਅਤੇ ਟਿੱਪਣੀ ਲਿਖਤ ਉਨ੍ਹਾਂ ਸਥਾਨਕ ਫਾਈਲਾਂ ਵਿੱਚ ਰਹਿੰਦੀ ਹੈ (ਕਾਪੀ ਕਰੋ ਤਾਂ ਕਲਿੱਪਬੋਰਡ ਤੇ ਵੀ)। ਐਪ ਉਨ੍ਹਾਂ ਨੂੰ ਅੱਪਲੋਡ ਨਹੀਂ ਕਰਦੀ।

### ਲਾਗ

ਨਿਦਾਨ ਲਾਗ ਇੱਥੇ ਲਿਖੇ ਜਾ ਸਕਦੇ ਹਨ:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator\Logs`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator/Logs`

ਐਪ ਕਰੈਸ਼ ਹੋਵੇ ਤਾਂ ਡੈਸਕਟਾਪ ਤੇ ਸਥਾਨਕ ਗਲਤੀ ਰਿਪੋਰਟ ਫਾਈਲ ਲਿਖ ਸਕਦੀ ਹੈ। ਉਹ ਫਾਈਲ ਕਿਤੇ ਨਹੀਂ ਭੇਜੀ ਜਾਂਦੀ।

ਉਹ ਮੁੱਲ ਡਿਵੈਲਪਰ ਨੂੰ ਅੱਪਲੋਡ ਨਹੀਂ ਹੁੰਦੇ।

ਤੁਹਾਡਾ ਡਾਟਾ ਸੰਭਾਲਣ ਲਈ ਡਿਵੈਲਪਰ ਸਰਵਰ ਨਹੀਂ ਵਰਤਿਆ ਜਾਂਦਾ।

## ਸਕ੍ਰੀਨ ਕੈਪਚਰ ਅਤੇ OCR

Print Screen (ਜਾਂ ਸਕ੍ਰੀਨਸ਼ਾਟ ਕਮਾਂਡ) ਵਰਤਣ ਤੇ ਐਪ ਮੌਜੂਦਾ ਸਕ੍ਰੀਨ ਕੈਪਚਰ ਕਰਦੀ ਹੈ ਤਾਂ ਜੋ ਤੁਸੀਂ ਕੱਟ ਕੇ ਟਿੱਪਣੀ ਕਰ ਸਕੋ। ਕੈਪਚਰ ਸਿਰਫ ਇਸ ਡਿਵਾਈਸ ਤੇ ਹੁੰਦਾ ਹੈ।

OCR ਸਥਾਨਕ ਤੌਰ ਤੇ ਚੱਲਦਾ ਹੈ:

- **Windows OCR** ਇਸ PC ਤੇ ਓਪਰੇਟਿੰਗ ਸਿਸਟਮ ਦੇ `Windows.Media.Ocr` API ਵਰਤਦਾ ਹੈ।
- **Tesseract** ਇੰਸਟਾਲ ਹੋਵੇ ਅਤੇ PATH ਵਿੱਚ ਹੋਵੇ ਤਾਂ ਇਸ ਕੰਪਿਊਟਰ ਤੇ ਚੱਲਦਾ ਹੈ।

ਪਛਾਣੀ ਲਿਖਤ ਐਪ ਵਿੱਚ ਦਿਖਾਈ ਜਾਂਦੀ ਹੈ ਤਾਂ ਜੋ ਕਾਪੀ ਜਾਂ ਸੋਧ ਕਰ ਸਕੋ। ਡਿਵੈਲਪਰ ਨੂੰ ਨਹੀਂ ਭੇਜੀ ਜਾਂਦੀ।

## ਨੈੱਟਵਰਕ ਵਰਤੋਂ

### ਅੱਪਡੇਟ ਜਾਂਚ

Store ਤੋਂ ਬਾਹਰ ਬਿਲਡ ਨਵੀਨਤਮ GitHub ਰਿਲੀਜ਼ ਮੰਗ ਸਕਦੇ ਹਨ:

`https://api.github.com/repos/drweb86/annotator/releases/latest`

GitHub (Microsoft) ਆਮ HTTPS ਬੇਨਤੀ (IP ਪਤਾ, user-agent, ਸਮਾਂ) ਪ੍ਰਾਪਤ ਕਰਦਾ ਹੈ। ਡਿਵੈਲਪਰ ਉਹ ਟ੍ਰੈਫਿਕ ਨਹੀਂ ਪ੍ਰਾਪਤ ਕਰਦਾ।

Microsoft Store ਇੰਸਟਾਲ ਇਸ ਜਾਂਚ ਨੂੰ ਨਹੀਂ ਵਰਤਦੇ; ਅੱਪਡੇਟ Store ਪਹੁੰਚਾਉਂਦਾ ਹੈ।

### ਲਿੰਕ ਜੋ ਤੁਸੀਂ ਖੋਲ੍ਹਦੇ ਹੋ

ਐਪ ਸਿਸਟਮ ਬ੍ਰਾਊਜ਼ਰ ਵਿੱਚ ਇਹ ਪੰਨੇ ਖੋਲ੍ਹ ਸਕਦੀ ਹੈ। ਉਨ੍ਹਾਂ ਸਾਈਟਾਂ ਦੀਆਂ ਆਪਣੀਆਂ ਪਰਦੇਦਾਰੀ ਨੀਤੀਆਂ ਹਨ:

- ਪ੍ਰੋਜੈਕਟ ਹੋਮਪੇਜ: [github.com/drweb86/annotator](https://github.com/drweb86/annotator)
- ਨਵੀਨਤਮ ਰਿਲੀਜ਼: [github.com/drweb86/annotator/releases/latest](https://github.com/drweb86/annotator/releases/latest)

ਲਾਇਸੈਂਸ ਐਪ ਅੰਦਰ ਦਿਖਾਇਆ ਜਾਂਦਾ ਹੈ। ਵੈੱਬ ਪੰਨੇ ਵਜੋਂ ਨਹੀਂ ਖੋਲ੍ਹਿਆ ਜਾਂਦਾ।

## ਹੋਰ ਸਥਾਨਕ ਵਿਹਾਰ

Windows ਜਾਂ Linux ਵਿੱਚ ਸਾਈਨ ਇਨ ਕਰਨ ਤੇ ਐਪ ਸ਼ੁਰੂ ਕਰ ਸਕਦੇ ਹੋ। Windows ਤੇ ਸਟਾਰਟਅੱਪ ਐਂਟਰੀ (Store ਇੰਸਟਾਲ ਲਈ Microsoft Store ਸਟਾਰਟਅੱਪ ਕਾਰਜ) ਵਰਤੀ ਜਾਂਦੀ ਹੈ। Linux ਤੇ autostart ਐਂਟਰੀ। ਉਹ ਸਿਰਫ ਇਸ ਐਪ ਨੂੰ ਤੁਹਾਡੇ ਕੰਪਿਊਟਰ ਤੇ ਚਾਲੂ ਕਰਦੀ ਹੈ।

ਵਿਕਲਪਿਕ ਗਲੋਬਲ Print Screen ਹਾਟਕੀ ਐਪ ਚੱਲਣ ਵੇਲੇ ਮੈਮੋਰੀ ਵਿੱਚ ਰਹਿੰਦੀ ਹੈ ਤਾਂ ਜੋ ਚੋਣਕਾਰ ਖੁੱਲ੍ਹ ਸਕੇ।

## ਬੱਚੇ

ਐਪ ਸਕ੍ਰੀਨਸ਼ਾਟ ਟਿੱਪਣੀ ਔਜ਼ਾਰ ਹੈ। 13 ਸਾਲ ਤੋਂ ਘੱਟ ਬੱਚਿਆਂ ਲਈ ਨਹੀਂ ਹੈ।

## ਤੀਜੀਆਂ ਧਿਰਾਂ

GitHub ਉੱਪਰ ਵਾਂਗ ਅੱਪਡੇਟ ਜਾਂਚ ਅਤੇ ਤੁਸੀਂ ਖੋਲ੍ਹਦੇ ਪੰਨੇ ਪ੍ਰਕਿਰਿਆ ਕਰਦਾ ਹੈ। Microsoft Store Store ਇੰਸਟਾਲ ਅਤੇ ਅੱਪਡੇਟ ਪ੍ਰਕਿਰਿਆ ਕਰਦਾ ਹੈ। Windows OCR ਓਪਰੇਟਿੰਗ ਸਿਸਟਮ ਦਿੰਦਾ ਹੈ। ਡਿਵੈਲਪਰ ਉਹ ਟ੍ਰੈਫਿਕ ਨਹੀਂ ਪ੍ਰਾਪਤ ਕਰਦਾ।

## ਤਬਦੀਲੀਆਂ
