# ગોપનીયતા નીતિ

છેલ્લે અપડેટ: 20 સપ્ટેમ્બર 2026

**Screenshot Annotator** by Siarhei Kuchuk

એપ્લિકેશનનું નામ: Screenshot Annotator
ડેવલપરનું નામ: Siarhei Kuchuk

સોફ્ટવેર આ કમ્પ્યુટર પર સ્ક્રીનશૉટ લે છે, ટિપ્પણી કરવા દે છે અને OCR વડે પસંદ કરેલ વિસ્તારમાંથી ટેક્સ્ટ વાંચી શકે છે. તે ક્લાઉડ એકાઉન્ટ બનાવતું નથી. ડેવલપર તમારા સ્ક્રીનશૉટ, પ્રોજેક્ટ અથવા વપરાશ ડેટા મેળવતું સર્વર ચલાવતા નથી.

## ડેવલપર જે ડેટા એકત્ર કરતા નથી

એપમાં જાહેરાત, વિશ્લેષણ, ક્રેશ રિપોર્ટર અથવા ટ્રેકિંગ SDK નથી. ડેવલપર વ્યક્તિગત ડેટા એકત્ર, વેચતા કે શેર કરતા નથી.

## તમારા કમ્પ્યુટર પર સંગ્રહિત ડેટા

### સેટિંગ્સ

એપ્લિકેશન સેટિંગ્સ (Print Screen હોટકી, સિસ્ટમ સાથે શરૂઆત, OCR એન્જિન અને ભાષાઓ, હાઇલાઇટર રંગ, અને લાઇસન્સ અથવા ગોપનીયતા વિન્ડોમાં છેલ્લી પસંદ કરેલ ભાષા) ફક્ત આ કમ્પ્યુટર પર સંગ્રહિત થાય છે:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator`

### પ્રોજેક્ટ અને છબીઓ

ટિપ્પણી કરેલ પ્રોજેક્ટ અને પૂર્વાવલોકન છબીઓ ફોલ્ડરમાં સંગ્રહિત થાય છે:

- Windows: `%USERPROFILE%\Pictures\ScreenshotAnnotator`
- Linux: `~/Pictures/ScreenshotAnnotator`

સ્ક્રીનશૉટ, આયાત કરેલ છબીઓ અને ટિપ્પણી ટેક્સ્ટ તે સ્થાનિક ફાઇલોમાં રહે છે (કૉપિ કરો તો ક્લિપબોર્ડ પર પણ). એપ તેમને અપલોડ કરતી નથી.

### લૉગ્સ

નિદાન લૉગ્સ અહીં લખાઈ શકે છે:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator\Logs`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator/Logs`

એપ ક્રેશ થાય તો ડેસ્કટોપ પર સ્થાનિક ભૂલ અહેવાલ ફાઇલ લખી શકે છે. તે ફાઇલ ક્યાંય મોકલાતી નથી.

તે મૂલ્યો ડેવલપરને અપલોડ થતા નથી.

તમારો ડેટા સંગ્રહવા માટે ડેવલપર સર્વર વપરાતું નથી.

## સ્ક્રીન કેપ્ચર અને OCR

Print Screen (અથવા સ્ક્રીનશૉટ આદેશ) વાપરો ત્યારે એપ વર્તમાન સ્ક્રીન કેપ્ચર કરે છે જેથી તમે કાપીને ટિપ્પણી કરી શકો. કેપ્ચર ફક્ત આ ઉપકરણ પર થાય છે.

OCR સ્થાનિક રીતે ચાલે છે:

- **Windows OCR** આ PC પર ઑપરેટિંગ સિસ્ટમના `Windows.Media.Ocr` API વાપરે છે.
- **Tesseract** ઇન્સ્ટોલ હોય અને PATH માં હોય તો આ કમ્પ્યુટર પર ચાલે છે.

ઓળખાયેલ ટેક્સ્ટ એપમાં બતાવાય છે જેથી કૉપિ અથવા સંપાદન કરી શકો. ડેવલપરને મોકલાતું નથી.

## નેટવર્ક ઉપયોગ

### અપડેટ તપાસ

Store સિવાયના બિલ્ડ તાજેતરની GitHub રિલીઝ માંગી શકે છે:

`https://api.github.com/repos/drweb86/annotator/releases/latest`

GitHub (Microsoft) સામાન્ય HTTPS વિનંતી (IP સરનામું, user-agent, સમય) મેળવે છે. ડેવલપર તે ટ્રાફિક મેળવતા નથી.

Microsoft Store ઇન્સ્ટોલ આ તપાસ વાપરતા નથી; અપડેટ Store પહોંચાડે છે.

### તમે ખોલો છો તે લિંક્સ

એપ સિસ્ટમ બ્રાઉઝરમાં આ પાનાં ખોલી શકે છે. તે સાઇટની પોતાની ગોપનીયતા નીતિ છે:

- પ્રોજેક્ટ હોમપેજ: [github.com/drweb86/annotator](https://github.com/drweb86/annotator)
- તાજેતરની રિલીઝ: [github.com/drweb86/annotator/releases/latest](https://github.com/drweb86/annotator/releases/latest)

લાઇસન્સ એપની અંદર બતાવાય છે. વેબ પાનું તરીકે ખુલતું નથી.

## અન્ય સ્થાનિક વર્તન

Windows અથવા Linux માં સાઇન ઇન કરો ત્યારે એપ શરૂ કરી શકો છો. Windows પર સ્ટાર્ટઅપ એન્ટ્રી (Store ઇન્સ્ટોલ માટે Microsoft Store સ્ટાર્ટઅપ ટાસ્ક) વપરાય છે. Linux પર autostart એન્ટ્રી. તે ફક્ત આ એપ તમારા કમ્પ્યુટર પર શરૂ કરે છે.

વૈકલ્પિક વૈશ્વિક Print Screen હોટકી એપ ચાલે ત્યાં સુધી મેમરીમાં રહે છે જેથી પસંદગીકાર ખુલે.

GitHub ઉપર મુજબ અપડેટ તપાસ અને તમે ખોલો છો તે પાનાં પ્રક્રિયા કરે છે. Microsoft Store Store ઇન્સ્ટોલ અને અપડેટ પ્રક્રિયા કરે છે. Windows OCR ઑપરેટિંગ સિસ્ટમ પૂરું પાડે છે. ડેવલપર તે ટ્રાફિક મેળવતા નથી.
