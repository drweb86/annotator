# गोपनीयता नीति

पछिल्लो अद्यावधिक: २० सेप्टेम्बर २०२६

**Screenshot Annotator** by Siarhei Kuchuk

अनुप्रयोगको नाम: Screenshot Annotator
विकासकर्ताको नाम: Siarhei Kuchuk

सफ्टवेयरले यस कम्प्युटरमा स्क्रिनसट खिच्छ, एनोटेसन गर्न दिन्छ, र OCR ले चयन गरिएको क्षेत्रबाट पाठ पढ्न सक्छ। यसले क्लाउड खाता बनाउँदैन। विकासकर्ताले तपाईंका स्क्रिनसट, परियोजना वा प्रयोग डेटा प्राप्त गर्ने सर्भर सञ्चालन गर्दैनन्।

## विकासकर्ताले नजम्मा गर्ने डेटा

एपमा विज्ञापन, विश्लेषण, क्र्यास रिपोर्टर वा ट्र्याकिङ SDK छैन। विकासकर्ताले व्यक्तिगत डेटा जम्मा, बिक्री वा साझा गर्दैनन्।

## तपाईंको कम्प्युटरमा भण्डारण गरिएको डेटा

### सेटिङहरू

अनुप्रयोग सेटिङहरू (Print Screen हटकी, प्रणालीसँग सुरुवात, OCR इन्जिन र भाषाहरू, हाइलाइटर रङ, र इजाजतपत्र वा गोपनीयता सञ्झ्यालमा अन्तिम चयन गरिएको भाषा) यस कम्प्युटरमा मात्र भण्डारण हुन्छन्:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator`

### परियोजना र छविहरू

एनोटेसन गरिएका परियोजना र पूर्वावलोकन तस्बिर फोल्डरमा भण्डारण हुन्छन्:

- Windows: `%USERPROFILE%\Pictures\ScreenshotAnnotator`
- Linux: `~/Pictures/ScreenshotAnnotator`

स्क्रिनसट, आयात गरिएका छवि र एनोटेसन पाठ ती स्थानीय फाइलमा रहन्छन् (कपी गरे क्लिपबोर्डमा पनि)। एपले तिनीहरू अपलोड गर्दैन।

### लगहरू

निदान लगहरू यहाँ लेखिन सक्छन्:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator\Logs`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator/Logs`

एप क्र्यास भए डेस्कटपमा स्थानीय त्रुटि प्रतिवेदन फाइल लेख्न सक्छ। त्यो फाइल कतै पठाइँदैन।

ती मान विकासकर्तालाई अपलोड हुँदैनन्।

तपाईंको डेटा भण्डारण गर्न विकासकर्ता सर्भर प्रयोग हुँदैन।

## स्क्रिन क्याप्चर र OCR

Print Screen (वा स्क्रिनसट आदेश) प्रयोग गर्दा एपले हालको स्क्रिन क्याप्चर गर्छ ताकि तपाईं काटेर एनोटेसन गर्न सक्नुहोस्। क्याप्चर यस यन्त्रमा मात्र हुन्छ।

OCR स्थानीय रूपमा चल्छ:

- **Windows OCR** यस PC मा अपरेटिङ सिस्टमका `Windows.Media.Ocr` API प्रयोग गर्छ।
- **Tesseract** स्थापना भए र PATH मा भए यस कम्प्युटरमा चल्छ।

चिनाइएको पाठ एपमा देखाइन्छ ताकि कपी वा सम्पादन गर्न सकियोस्। विकासकर्तालाई पठाइँदैन।

## सञ्जाल प्रयोग

### अद्यावधिक जाँच

Store बाहिरका बिल्डले नवीनतम GitHub रिलिज अनुरोध गर्न सक्छन्:

`https://api.github.com/repos/drweb86/annotator/releases/latest`

GitHub (Microsoft) सामान्य HTTPS अनुरोध (IP ठेगाना, user-agent, समय) प्राप्त गर्छ। विकासकर्ताले त्यो ट्राफिक प्राप्त गर्दैनन्।

Microsoft Store स्थापनाले यो जाँच प्रयोग गर्दैनन्; अद्यावधिक Store ले पुर्‍याउँछ।

### तपाईंले खोल्ने लिङ्कहरू

एपले प्रणाली ब्राउजरमा यी पृष्ठ खोल्न सक्छ। ती साइटका आफ्नै गोपनीयता नीति छन्:

- परियोजना गृहपृष्ठ: [github.com/drweb86/annotator](https://github.com/drweb86/annotator)
- नवीनतम रिलिज: [github.com/drweb86/annotator/releases/latest](https://github.com/drweb86/annotator/releases/latest)

इजाजतपत्र एपभित्र देखाइन्छ। वेब पृष्ठका रूपमा खोलिँदैन।

## अन्य स्थानीय व्यवहार

Windows वा Linux मा साइन इन गर्दा एप सुरु गर्न सक्नुहुन्छ। Windows मा स्टार्टअप प्रविष्टि (Store स्थापनाका लागि Microsoft Store स्टार्टअप कार्य) प्रयोग हुन्छ। Linux मा autostart प्रविष्टि। त्यो तपाईंको कम्प्युटरमा यो एप मात्र सुरु गर्छ।

वैकल्पिक विश्वव्यापी Print Screen हटकी एप चलिरहेका बेला मेमोरीमा रहन्छ ताकि चयनकर्ता खोल्न सकियोस्।
