# رازداري پاليسي

آخري تازه ڪاري: 20 سيپٽمبر 2026

**Screenshot Annotator** by Siarhei Kuchuk

ايپليڪيشن جو نالو: Screenshot Annotator
ڊولپر جو نالو: Siarhei Kuchuk

سافٽ ويئر هن ڪمپيوٽر تي اسڪرين شاٽ وٺي ٿو، تشريح ڪرڻ ڏئي ٿو، ۽ OCR سان چونڊيل علائقي مان متن پڙهي سگهي ٿو. ڪلائوڊ اڪائونٽ ناهي ٺاهيندو. ڊولپر اهو سرور ناهي هلائيندو جيڪو توهان جا اسڪرين شاٽ، منصوبا يا استعمال ڊيٽا وصول ڪري.

## ڊيٽا جيڪا ڊولپر گڏ ناهي ڪندو

ايپ ۾ اشتهار، تجزيو، ڪريش رپورٽر يا ٽريڪنگ SDK ناهي. ڊولپر ذاتي ڊيٽا گڏ، وڪرو يا شيئر ناهي ڪندو.

## توهان جي ڪمپيوٽر تي محفوظ ڊيٽا

### سيٽنگون

ايپليڪيشن سيٽنگون (Print Screen هاٽڪي، سسٽم سان شروع، OCR انجڻ ۽ ٻوليون، هائي لائيٽر رنگ، ۽ لائسنس يا رازداري ونڊو ۾ آخري چونڊيل ٻولي) صرف هن ڪمپيوٽر تي محفوظ آهن:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator`

### منصوبا ۽ تصويرون

تشريح ٿيل منصوبا ۽ پيش منظر تصويرون فولڊر ۾ محفوظ آهن:

- Windows: `%USERPROFILE%\Pictures\ScreenshotAnnotator`
- Linux: `~/Pictures/ScreenshotAnnotator`

اسڪرين شاٽ، درآمد ٿيل تصويرون ۽ تشريح متن انهن مقامي فائلن ۾ رهن ٿا (ڪاپي ڪريو ته ڪلپ بورڊ تي به). ايپ انهن کي اپلوڊ ناهي ڪندي.

### لاگ

تشخيصي لاگ هتي لکي سگهجن ٿا:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator\Logs`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator/Logs`

جيڪڏهن ايپ ڪريش ٿئي، ڊيسڪ ٽاپ تي مقامي غلطي رپورٽ فائل لکي سگهي ٿي. اها فائل ڪٿي به نه موڪلي ويندي.

اهي قدر ڊولپر ڏانهن اپلوڊ ناهن ٿيندا.

توهان جي ڊيٽا محفوظ ڪرڻ لاءِ ڊولپر سرور استعمال ناهي ٿيندو.

## اسڪرين ڪيپچر ۽ OCR

Print Screen (يا اسڪرين شاٽ حڪم) استعمال ڪريو ته ايپ موجوده اسڪرين ڪيپچر ڪري ٿي ته جيئن ڪٽي تشريح ڪري سگهو. ڪيپچر صرف هن ڊوائيس تي ٿئي ٿو.

OCR مقامي طور هلندو آهي:

- **Windows OCR** هن PC تي آپريٽنگ سسٽم جي `Windows.Media.Ocr` API استعمال ڪري ٿو.
- **Tesseract** انسٽال هجي ۽ PATH ۾ هجي ته هن ڪمپيوٽر تي هلندو آهي.

سڃاتل متن ايپ ۾ ڏيکاريو وڃي ٿو ته جيئن ڪاپي يا ترميم ڪري سگهو. ڊولپر ڏانهن نه موڪليو وڃي ٿو.

## نيٽ ورڪ استعمال

### تازه ڪاري چيڪ

Store کان ٻاهر بلڊ تازي GitHub رليز گهري سگهن ٿا:

`https://api.github.com/repos/drweb86/annotator/releases/latest`

GitHub (Microsoft) عام HTTPS درخواست (IP پتو، user-agent، وقت) وصول ڪري ٿو. ڊولپر اهو ٽريفڪ وصول ناهي ڪندو.

Microsoft Store انسٽال هي چيڪ استعمال ناهن ڪندا؛ تازه ڪاريون Store پهچائي ٿو.

### لنڪ جيڪي توهان کوليو ٿا

ايپ سسٽم برائوزر ۾ هي صفحا کولي سگهي ٿي. انهن سائيٽن جون پنهنجون رازداري پاليسيون آهن:

- منصوبي جو مکيه صفحو: [github.com/drweb86/annotator](https://github.com/drweb86/annotator)
- تازي رليز: [github.com/drweb86/annotator/releases/latest](https://github.com/drweb86/annotator/releases/latest)

لائسنس ايپ اندر ڏيکاريو وڃي ٿو. ويب صفحي طور ناهي کوليو ويندو.

## ٻيو مقامي ورتاءُ

Windows يا Linux ۾ سائن ان ڪريو ته ايپ شروع ڪري سگهو ٿا. Windows تي اسٽارٽ اپ داخلا (Store انسٽال لاءِ Microsoft Store اسٽارٽ اپ ڪم) استعمال ٿئي ٿي. Linux تي autostart داخلا. اهو صرف هي ايپ توهان جي ڪمپيوٽر تي شروع ڪري ٿو.

اختياري عالمي Print Screen هاٽڪي ايپ هلندي ميموري ۾ رهي ٿي ته جيئن چونڊيندڙ کلي سگهي.
