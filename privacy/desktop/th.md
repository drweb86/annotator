# นโยบายความเป็นส่วนตัว

อัปเดตล่าสุด: 20 กันยายน 2026

**Screenshot Annotator** by Siarhei Kuchuk

ชื่อแอปพลิเคชัน: Screenshot Annotator
ชื่อผู้พัฒนา: Siarhei Kuchuk

ซอฟต์แวร์จับภาพหน้าจอบนคอมพิวเตอร์นี้ ให้ใส่คำอธิบายประกอบ และอ่านข้อความจากพื้นที่ที่เลือกด้วย OCR ไม่สร้างบัญชีคลาวด์ ผู้พัฒนาไม่ให้บริการเซิร์ฟเวอร์ที่รับภาพหน้าจอ โครงการ หรือข้อมูลการใช้งานของคุณ

## ข้อมูลที่ผู้พัฒนาไม่เก็บ

แอปไม่มีโฆษณา การวิเคราะห์ รายงานข้อขัดข้อง หรือ SDK ติดตาม ผู้พัฒนาไม่เก็บ ขาย หรือแชร์ข้อมูลส่วนบุคคล

## ข้อมูลที่เก็บไว้ในคอมพิวเตอร์ของคุณ

### การตั้งค่า

การตั้งค่าแอป (ปุ่มลัด Print Screen, เริ่มพร้อมระบบ, เอนจิน OCR และภาษา, สีปากกาเน้นข้อความ และภาษาที่เลือกครั้งล่าสุดในหน้าต่างสัญญาอนุญาตหรือความเป็นส่วนตัว) ถูกเก็บไว้เฉพาะคอมพิวเตอร์นี้:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator`

### โครงการและรูปภาพ

โครงการที่มีคำอธิบายและภาพตัวอย่างถูกเก็บในโฟลเดอร์รูปภาพ:

- Windows: `%USERPROFILE%\Pictures\ScreenshotAnnotator`
- Linux: `~/Pictures/ScreenshotAnnotator`

ภาพหน้าจอ รูปที่นำเข้า และข้อความคำอธิบายอยู่ในไฟล์ท้องถิ่นเหล่านี้ (หรือคลิปบอร์ดหากคุณคัดลอก) แอปไม่ได้อัปโหลด

### บันทึก

บันทึกการวินิจฉัยอาจถูกเขียนที่:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator\Logs`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator/Logs`

หากแอปขัดข้อง อาจเขียนไฟล์รายงานข้อผิดพลาดในเครื่องบนเดสก์ท็อป ไฟล์นั้นไม่ถูกส่งไปที่ใด

ค่าเหล่านี้ไม่ถูกอัปโหลดไปยังผู้พัฒนา

ไม่ใช้เซิร์ฟเวอร์ของผู้พัฒนาเพื่อเก็บข้อมูลของคุณ

## การจับหน้าจอและ OCR

เมื่อใช้ Print Screen (หรือคำสั่งจับภาพ) แอปจะจับหน้าจอปัจจุบันเพื่อให้ครอบตัดและใส่คำอธิบาย การจับเกิดขึ้นบนอุปกรณ์นี้เท่านั้น

OCR ทำงานในเครื่อง:

- **Windows OCR** ใช้ API `Windows.Media.Ocr` ของระบบปฏิบัติการบนพีซีนี้
- **Tesseract** ทำงานบนคอมพิวเตอร์นี้หากติดตั้งและอยู่ใน PATH

ข้อความที่รู้จำจะแสดงในแอปเพื่อคัดลอกหรือแก้ไข ไม่ถูกส่งไปยังผู้พัฒนา

## การใช้เครือข่าย

### ตรวจการอัปเดต

บิลด์ที่ไม่ใช่ Store อาจขอรุ่นล่าสุดจาก GitHub:

`https://api.github.com/repos/drweb86/annotator/releases/latest`

GitHub (Microsoft) ได้รับคำขอ HTTPS ปกติ (ที่อยู่ IP, user-agent, เวลา) ผู้พัฒนาไม่ได้รับทราฟฟิกนั้น

การติดตั้งจาก Microsoft Store ไม่ใช้การตรวจนี้ Store เป็นผู้ส่งการอัปเดต

### ลิงก์ที่คุณเปิด

แอปสามารถเปิดหน้าเหล่านี้ในเบราว์เซอร์ของระบบ ไซต์เหล่านั้นมีนโยบายความเป็นส่วนตัวของตนเอง:

- หน้าแรกของโครงการ: [github.com/drweb86/annotator](https://github.com/drweb86/annotator)
- รุ่นล่าสุด: [github.com/drweb86/annotator/releases/latest](https://github.com/drweb86/annotator/releases/latest)

สัญญาอนุญาตแสดงภายในแอป ไม่เปิดเป็นหน้าเว็บ

## พฤติกรรมในเครื่องอื่น

คุณให้แอปเริ่มเมื่อลงชื่อเข้าใช้ Windows หรือ Linux ได้ บน Windows ใช้รายการเริ่มต้น (หรืองานเริ่มต้น Microsoft Store สำหรับการติดตั้ง Store) บน Linux ใช้รายการ autostart การนี้เริ่มเฉพาะแอปนี้บนคอมพิวเตอร์ของคุณ

ปุ่มลัด Print Screen ส่วนกลางที่เป็นทางเลือกจะอยู่ในหน่วยความจำขณะแอปทำงานเพื่อเปิดตัวเลือกพื้นที่
