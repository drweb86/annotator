# سیاست حفظ حریم خصوصی

آخرین به‌روزرسانی: ۲۰ سپتامبر ۲۰۲۶

**Screenshot Annotator** by Siarhei Kuchuk

نام برنامه: Screenshot Annotator
نام توسعه‌دهنده: Siarhei Kuchuk

نرم‌افزار روی این رایانه نماگرفت می‌گیرد، امکان حاشیه‌نویسی می‌دهد و می‌تواند متن ناحیهٔ انتخاب‌شده را با OCR بخواند. حساب ابری نمی‌سازد. توسعه‌دهنده سروری ندارد که نماگرفت‌ها، پروژه‌ها یا داده‌های استفاده شما را دریافت کند.

## داده‌هایی که توسعه‌دهنده جمع نمی‌کند

برنامه تبلیغات، تحلیل، گزارش خرابی یا SDK ردیابی ندارد. توسعه‌دهنده دادهٔ شخصی جمع، فروش یا به اشتراک نمی‌گذارد.

## داده‌های ذخیره‌شده روی رایانه شما

### تنظیمات

تنظیمات برنامه (میانبر Print Screen، شروع همراه سیستم، موتور OCR و زبان‌ها، رنگ هایلایتر و آخرین زبان انتخاب‌شده در پنجرهٔ مجوز یا حریم خصوصی) فقط روی این رایانه ذخیره می‌شود:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator`

### پروژه‌ها و تصویرها

پروژه‌های حاشیه‌نویسی‌شده و پیش‌نمایش‌ها در پوشهٔ تصاویر ذخیره می‌شوند:

- Windows: `%USERPROFILE%\Pictures\ScreenshotAnnotator`
- Linux: `~/Pictures/ScreenshotAnnotator`

نماگرفت‌ها، تصویرهای واردشده و متن حاشیه‌ها در این پرونده‌های محلی می‌مانند (یا در کلیپ‌بورد اگر رونویسی کنید). برنامه آن‌ها را بارگذاری نمی‌کند.

### گزارش‌ها

گزارش‌های تشخیصی ممکن است در اینجا نوشته شوند:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator\Logs`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator/Logs`

اگر برنامه از کار بیفتد، ممکن است پروندهٔ گزارش خطای محلی روی میزکار بنویسد. آن پرونده به جایی فرستاده نمی‌شود.

این مقادیر برای توسعه‌دهنده بارگذاری نمی‌شوند.

هیچ سرور توسعه‌دهنده‌ای برای ذخیرهٔ داده‌های شما استفاده نمی‌شود.

## گرفتن صفحه و OCR

وقتی Print Screen (یا فرمان نماگرفت) را استفاده می‌کنید، برنامه صفحهٔ جاری را می‌گیرد تا برش و حاشیه‌نویسی کنید. گرفتن فقط روی این دستگاه انجام می‌شود.

OCR به‌صورت محلی اجرا می‌شود:

- **Windows OCR** از APIهای `Windows.Media.Ocr` سیستم‌عامل روی این رایانه استفاده می‌کند.
- **Tesseract** اگر نصب باشد و در PATH باشد روی این رایانه اجرا می‌شود.

متن شناسایی‌شده در برنامه نشان داده می‌شود تا رونویسی یا ویرایش کنید. به توسعه‌دهنده فرستاده نمی‌شود.

## استفاده از شبکه

### بررسی به‌روزرسانی

نسخه‌های غیر Store ممکن است آخرین انتشار GitHub را بخواهند:

`https://api.github.com/repos/drweb86/annotator/releases/latest`

GitHub (Microsoft) یک درخواست HTTPS عادی (نشانی IP، user-agent، زمان) دریافت می‌کند. توسعه‌دهنده آن ترافیک را دریافت نمی‌کند.

نصب‌های Microsoft Store از این بررسی استفاده نمی‌کنند؛ Store به‌روزرسانی‌ها را می‌رساند.

### پیوندهایی که باز می‌کنید

برنامه می‌تواند این صفحه‌ها را در مرورگر سیستم باز کند. آن سایت‌ها سیاست حفظ حریم خصوصی خود را دارند:

- صفحهٔ پروژه: [github.com/drweb86/annotator](https://github.com/drweb86/annotator)
- آخرین انتشار: [github.com/drweb86/annotator/releases/latest](https://github.com/drweb86/annotator/releases/latest)

مجوز داخل برنامه نشان داده می‌شود. به‌صورت صفحهٔ وب باز نمی‌شود.

## رفتار محلی دیگر

می‌توانید برنامه را هنگام ورود به Windows یا Linux شروع کنید. در Windows از ورودی راه‌اندازی (یا وظیفهٔ راه‌اندازی Microsoft Store برای نصب‌های Store) استفاده می‌شود. در Linux از ورودی autostart. این فقط همین برنامه را روی رایانه شما اجرا می‌کند.

میانبر سراسری اختیاری Print Screen تا وقتی برنامه اجرا می‌شود در حافظه می‌ماند تا پنجرهٔ انتخاب باز شود.

## اشخاص ثالث

GitHub بررسی به‌روزرسانی و صفحه‌هایی را که باز می‌کنید طبق بالا پردازش می‌کند. Microsoft Store نصب و به‌روزرسانی Store را پردازش می‌کند. Windows OCR را سیستم‌عامل فراهم می‌کند. توسعه‌دهنده آن ترافیک را دریافت نمی‌کند.
