# தனியுரிமைக் கொள்கை

கடைசியாக புதுப்பிக்கப்பட்டது: 20 செப்டம்பர் 2026

**Screenshot Annotator** by Siarhei Kuchuk

பயன்பாட்டின் பெயர்: Screenshot Annotator
உருவாக்குநரின் பெயர்: Siarhei Kuchuk

மென்பொருள் இந்தக் கணினியில் திரைப்பிடிப்புகளை எடுக்கிறது, குறிப்புகள் இட அனுமதிக்கிறது, மேலும் OCR மூலம் தேர்ந்தெடுத்த பகுதியிலிருந்து உரையைப் படிக்கலாம். மேகக் கணக்குகளை உருவாக்காது. உருவாக்குநர் உங்கள் திரைப்பிடிப்புகள், திட்டங்கள் அல்லது பயன்பாட்டுத் தரவைப் பெறும் சேவையகத்தை இயக்குவதில்லை.

## உருவாக்குநர் சேகரிக்காத தரவு

பயன்பாட்டில் விளம்பரங்கள், பகுப்பாய்வு, செயலிழப்பு அறிக்கையாளர் அல்லது கண்காணிப்பு SDK இல்லை. உருவாக்குநர் தனிப்பட்ட தரவைச் சேகரிக்கவோ விற்கவோ பகிரவோ இல்லை.

## உங்கள் கணினியில் சேமிக்கப்படும் தரவு

### அமைப்புகள்

பயன்பாட்டு அமைப்புகள் (Print Screen குறுக்குவழி, அமைப்புடன் தொடக்கம், OCR இயந்திரம் மற்றும் மொழிகள், சிறப்புக்குறி நிறம், மற்றும் உரிமம் அல்லது தனியுரிமை சாளரத்தில் கடைசியாகத் தேர்ந்தெடுத்த மொழி) இந்தக் கணினியில் மட்டுமே சேமிக்கப்படும்:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator`

### திட்டங்கள் மற்றும் படங்கள்

குறிப்பு இடப்பட்ட திட்டங்களும் முன்னோட்டங்களும் படங்கள் கோப்புறையில் சேமிக்கப்படும்:

- Windows: `%USERPROFILE%\Pictures\ScreenshotAnnotator`
- Linux: `~/Pictures/ScreenshotAnnotator`

திரைப்பிடிப்புகள், இறக்குமதி செய்யப்பட்ட படங்கள் மற்றும் குறிப்பு உரை அந்த உள்ளூர் கோப்புகளில் இருக்கும் (நகலெடுத்தால் கிளிப்போர்டிலும்). பயன்பாடு அவற்றைப் பதிவேற்றாது.

### பதிவுகள்

நோயறிதல் பதிவுகள் இங்கே எழுதப்படலாம்:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator\Logs`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator/Logs`

பயன்பாடு செயலிழந்தால் டெஸ்க்டாப்பில் உள்ளூர் பிழை அறிக்கைக் கோப்பை எழுதலாம். அந்தக் கோப்பு எங்கும் அனுப்பப்படாது.

அந்த மதிப்புகள் உருவாக்குநருக்குப் பதிவேற்றப்படாது.

உங்கள் தரவைச் சேமிக்க உருவாக்குநர் சேவையகம் பயன்படுத்தப்படாது.

## திரைப் பிடிப்பு மற்றும் OCR

Print Screen (அல்லது திரைப்பிடிப்பு கட்டளை) பயன்படுத்தும்போது பயன்பாடு தற்போதைய திரையைப் பிடிக்கிறது, நீங்கள் வெட்டி குறிப்பு இட. பிடிப்பு இந்தச் சாதனத்தில் மட்டுமே நடக்கும்.

OCR உள்ளூரில் இயங்கும்:

- **Windows OCR** இந்த PC இல் இயக்க முறைமையின் `Windows.Media.Ocr` APIகளைப் பயன்படுத்துகிறது.
- **Tesseract** நிறுவப்பட்டு PATH இல் இருந்தால் இந்தக் கணினியில் இயங்கும்.

அறியப்பட்ட உரை பயன்பாட்டில் காட்டப்படும், நகலெடுக்க அல்லது திருத்த. உருவாக்குநருக்கு அனுப்பப்படாது.

## பிணையப் பயன்பாடு

### புதுப்பிப்பு சரிபார்ப்பு

Store அல்லாத உருவாக்கங்கள் சமீபத்திய GitHub வெளியீட்டைக் கோரலாம்:

`https://api.github.com/repos/drweb86/annotator/releases/latest`

GitHub (Microsoft) சாதாரண HTTPS கோரிக்கையை (IP முகவரி, user-agent, நேரம்) பெறுகிறது. உருவாக்குநர் அந்தப் போக்குவரத்தைப் பெறுவதில்லை.

Microsoft Store நிறுவல்கள் இந்தச் சரிபார்ப்பைப் பயன்படுத்துவதில்லை; புதுப்பிப்புகளை Store வழங்குகிறது.

### நீங்கள் திறக்கும் இணைப்புகள்

பயன்பாடு கணினி உலாவியில் இந்தப் பக்கங்களைத் திறக்கலாம். அந்த தளங்களுக்கு அவற்றின் சொந்த தனியுரிமைக் கொள்கைகள் உள்ளன:

- திட்ட முகப்பு: [github.com/drweb86/annotator](https://github.com/drweb86/annotator)
- சமீபத்திய வெளியீடு: [github.com/drweb86/annotator/releases/latest](https://github.com/drweb86/annotator/releases/latest)

உரிமம் பயன்பாட்டிற்குள் காட்டப்படும். வலைப்பக்கமாகத் திறக்கப்படாது.

## பிற உள்ளூர் நடத்தை

Windows அல்லது Linux இல் உள்நுழையும்போது பயன்பாட்டைத் தொடங்கலாம். Windows இல் தொடக்கப் பதிவு (Store நிறுவல்களுக்கு Microsoft Store தொடக்கப் பணி) பயன்படுத்தப்படும். Linux இல் autostart பதிவு. அது உங்கள் கணினியில் இந்தப் பயன்பாட்டை மட்டும் தொடங்கும்.

விருப்ப உலகளாவிய Print Screen குறுக்குவழி பயன்பாடு இயங்கும்போது நினைவகத்தில் இருக்கும், தேர்வியைத் திறக்க.
