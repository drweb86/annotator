# ଗୋପନୀୟତା ନୀତି

ଶେଷ ଅଦ୍ୟତନ: 20 ସେପ୍ଟେମ୍ବର 2026

**Screenshot Annotator** by Siarhei Kuchuk

ଆପ୍ଲିକେସନ୍ ନାମ: Screenshot Annotator
ଡେଭଲପର୍ ନାମ: Siarhei Kuchuk

ସଫ୍ଟୱେର୍ ଏହି କମ୍ପ୍ୟୁଟରରେ ସ୍କ୍ରିନସଟ୍ ନିଏ, ଟିପ୍ପଣୀ କରିବାକୁ ଦିଏ ଏବଂ OCR ଦ୍ୱାରା ଚୟନିତ ଅଞ୍ଚଳରୁ ପାଠ୍ୟ ପଢ଼ିପାରେ। ଏହା କ୍ଲାଉଡ୍ ଆକାଉଣ୍ଟ ସୃଷ୍ଟି କରେ ନାହିଁ। ଡେଭଲପର୍ ଆପଣଙ୍କ ସ୍କ୍ରିନସଟ୍, ପ୍ରକଳ୍ପ କିମ୍ବା ବ୍ୟବହାର ତଥ୍ୟ ଗ୍ରହଣ କରୁଥିବା ସର୍ଭର ଚଳାନ୍ତି ନାହିଁ।

## ଡେଭଲପର୍ ସଂଗ୍ରହ ନକରୁଥିବା ତଥ୍ୟ

ଆପ୍‌ରେ ବିଜ୍ଞାପନ, ବିଶ୍ଳେଷଣ, କ୍ରାସ୍ ରିପୋର୍ଟର୍ କିମ୍ବା ଟ୍ରାକିଂ SDK ନାହିଁ। ଡେଭଲପର୍ ବ୍ୟକ୍ତିଗତ ତଥ୍ୟ ସଂଗ୍ରହ, ବିକ୍ରି କିମ୍ବା ଅଂଶୀଦାର କରନ୍ତି ନାହିଁ।

## ଆପଣଙ୍କ କମ୍ପ୍ୟୁଟରରେ ସଂରକ୍ଷିତ ତଥ୍ୟ

### ସେଟିଂସ୍

ଆପ୍ଲିକେସନ୍ ସେଟିଂସ୍ (Print Screen ହଟକି, ସିଷ୍ଟମ୍ ସହିତ ଆରମ୍ଭ, OCR ଇଞ୍ଜିନ୍ ଓ ଭାଷା, ହାଇଲାଇଟର୍ ରଙ୍ଗ, ଏବଂ ଲାଇସେନ୍ସ କିମ୍ବା ଗୋପନୀୟତା ୱିଣ୍ଡୋରେ ଶେଷ ଚୟନିତ ଭାଷା) କେବଳ ଏହି କମ୍ପ୍ୟୁଟରରେ ସଂରକ୍ଷିତ ହୁଏ:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator`

### ପ୍ରକଳ୍ପ ଓ ପ୍ରତିଛବି

ଟିପ୍ପଣୀ କରାଯାଇଥିବା ପ୍ରକଳ୍ପ ଓ ପ୍ରିଭ୍ୟୁ ଛବି ଫୋଲ୍ଡରରେ ସଂରକ୍ଷିତ ହୁଏ:

- Windows: `%USERPROFILE%\Pictures\ScreenshotAnnotator`
- Linux: `~/Pictures/ScreenshotAnnotator`

ସ୍କ୍ରିନସଟ୍, ଆମଦାନୀ ପ୍ରତିଛବି ଓ ଟିପ୍ପଣୀ ପାଠ୍ୟ ସେହି ସ୍ଥାନୀୟ ଫାଇଲରେ ରହେ (କପି କଲେ କ୍ଲିପବୋର୍ଡରେ ମଧ୍ୟ)। ଆପ୍ ସେଗୁଡ଼ିକ ଅପଲୋଡ୍ କରେ ନାହିଁ।

### ଲଗ୍

ନିଦାନ ଲଗ୍ ଏଠାରେ ଲେଖାଯାଇପାରେ:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator\Logs`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator/Logs`

ଆପ୍ କ୍ରାସ୍ ହେଲେ ଡେସ୍କଟପ୍‌ରେ ସ୍ଥାନୀୟ ତ୍ରୁଟି ରିପୋର୍ଟ ଫାଇଲ୍ ଲେଖିପାରେ। ସେହି ଫାଇଲ୍ କେଉଁଠି ପଠାଯାଏ ନାହିଁ।

ସେହି ମୂଲ୍ୟ ଡେଭଲପର୍‌କୁ ଅପଲୋଡ୍ ହୁଏ ନାହିଁ।

ଆପଣଙ୍କ ତଥ୍ୟ ସଂରକ୍ଷଣ ପାଇଁ ଡେଭଲପର୍ ସର୍ଭର ବ୍ୟବହୃତ ହୁଏ ନାହିଁ।

## ସ୍କ୍ରିନ୍ କ୍ୟାପଚର୍ ଓ OCR

Print Screen (କିମ୍ବା ସ୍କ୍ରିନସଟ୍ ନିର୍ଦ୍ଦେଶ) ବ୍ୟବହାର କଲେ ଆପ୍ ବର୍ତ୍ତମାନ ସ୍କ୍ରିନ୍ ଧରେ ଯାହାଫଳରେ ଆପଣ କାଟି ଟିପ୍ପଣୀ କରିପାରିବେ। କ୍ୟାପଚର୍ କେବଳ ଏହି ଡିଭାଇସ୍‌ରେ ହୁଏ।

OCR ସ୍ଥାନୀୟ ଭାବେ ଚାଲେ:

- **Windows OCR** ଏହି PC ରେ ଅପରେଟିଂ ସିଷ୍ଟମ୍‌ର `Windows.Media.Ocr` API ବ୍ୟବହାର କରେ।
- **Tesseract** ସ୍ଥାପିତ ଥିଲେ ଏବଂ PATH ରେ ଥିଲେ ଏହି କମ୍ପ୍ୟୁଟରରେ ଚାଲେ।

ଚିହ୍ନିତ ପାଠ୍ୟ ଆପ୍‌ରେ ଦେଖାଯାଏ ଯାହାଫଳରେ କପି କିମ୍ବା ସମ୍ପାଦନ କରିପାରିବେ। ଡେଭଲପର୍‌କୁ ପଠାଯାଏ ନାହିଁ।

## ନେଟୱାର୍କ ବ୍ୟବହାର

### ଅଦ୍ୟତନ ଯାଞ୍ଚ

Store ବାହାରେ ଥିବା ବିଲ୍ଡ ନବୀନତମ GitHub ରିଲିଜ୍ ଅନୁରୋଧ କରିପାରେ:

`https://api.github.com/repos/drweb86/annotator/releases/latest`

GitHub (Microsoft) ସାଧାରଣ HTTPS ଅନୁରୋଧ (IP ଠିକଣା, user-agent, ସମୟ) ପାଏ। ଡେଭଲପର୍ ସେହି ଟ୍ରାଫିକ୍ ପାଆନ୍ତି ନାହିଁ।

Microsoft Store ଇନଷ୍ଟଲ୍ ଏହି ଯାଞ୍ଚ ବ୍ୟବହାର କରେ ନାହିଁ; ଅଦ୍ୟତନ Store ପହଞ୍ଚାଏ।

### ଆପଣ ଖୋଲୁଥିବା ଲିଙ୍କ୍

ଆପ୍ ସିଷ୍ଟମ୍ ବ୍ରାଉଜରରେ ଏହି ପୃଷ୍ଠା ଖୋଲିପାରେ। ସେହି ସାଇଟ୍‌ର ନିଜସ୍ୱ ଗୋପନୀୟତା ନୀତି ଅଛି:

- ପ୍ରକଳ୍ପ ମୂଳପୃଷ୍ଠା: [github.com/drweb86/annotator](https://github.com/drweb86/annotator)
- ନବୀନତମ ରିଲିଜ୍: [github.com/drweb86/annotator/releases/latest](https://github.com/drweb86/annotator/releases/latest)

ଲାଇସେନ୍ସ ଆପ୍ ଭିତରେ ଦେଖାଯାଏ। ୱେବ୍ ପୃଷ୍ଠା ଭାବେ ଖୋଲାଯାଏ ନାହିଁ।

## ଅନ୍ୟ ସ୍ଥାନୀୟ ଆଚରଣ

Windows କିମ୍ବା Linux ରେ ସାଇନ୍ ଇନ୍ କଲାବେଳେ ଆପ୍ ଆରମ୍ଭ କରିପାରିବେ। Windows ରେ ଷ୍ଟାର୍ଟଅପ୍ ଏଣ୍ଟ୍ରି (Store ଇନଷ୍ଟଲ୍ ପାଇଁ Microsoft Store ଷ୍ଟାର୍ଟଅପ୍ କାର୍ଯ୍ୟ) ବ୍ୟବହୃତ ହୁଏ। Linux ରେ autostart ଏଣ୍ଟ୍ରି। ତାହା କେବଳ ଏହି ଆପ୍ ଆପଣଙ୍କ କମ୍ପ୍ୟୁଟରରେ ଚଳାଏ।

ବୈକଳ୍ପିକ ବିଶ୍ୱ Print Screen ହଟକି ଆପ୍ ଚାଲିବା ସମୟରେ ମେମୋରିରେ ରହେ ଯାହାଫଳରେ ଚୟନକର୍ତ୍ତା ଖୋଲିପାରେ।

## ପିଲାମାନେ

ଆପ୍ ଏକ ସ୍କ୍ରିନସଟ୍ ଟିପ୍ପଣୀ ଉପକରଣ। 13 ବର୍ଷରୁ କମ୍ ପିଲାଙ୍କ ପାଇଁ ନୁହେଁ।

## ତୃତୀୟ ପକ୍ଷ

GitHub ଉପର ପରି ଅଦ୍ୟତନ ଯାଞ୍ଚ ଓ ଆପଣ ଖୋଲୁଥିବା ପୃଷ୍ଠା ପ୍ରକ୍ରିୟା କରେ। Microsoft Store Store ଇନଷ୍ଟଲ୍ ଓ ଅଦ୍ୟତନ ପ୍ରକ୍ରିୟା କରେ। Windows OCR ଅପରେଟିଂ ସିଷ୍ଟମ୍ ଦିଏ। ଡେଭଲପର୍ ସେହି ଟ୍ରାଫିକ୍ ପାଆନ୍ତି ନାହିଁ।
