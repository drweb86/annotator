# గోప్యతా విధానం

చివరిగా నవీకరించబడింది: 20 సెప్టెంబర్ 2026

**Screenshot Annotator** by Siarhei Kuchuk

అప్లికేషన్ పేరు: Screenshot Annotator
డెవలపర్ పేరు: Siarhei Kuchuk

సాఫ్ట్‌వేర్ ఈ కంప్యూటర్‌లో స్క్రీన్‌షాట్‌లు తీస్తుంది, వ్యాఖ్యానం చేయనిస్తుంది, మరియు OCR తో ఎంచుకున్న ప్రాంతం నుండి వచనం చదవగలదు. క్లౌడ్ ఖాతాలు సృష్టించదు. డెవలపర్ మీ స్క్రీన్‌షాట్‌లు, ప్రాజెక్ట్‌లు లేదా వినియోగ డేటా స్వీకరించే సర్వర్ నడపరు.

## డెవలపర్ సేకరించని డేటా

యాప్‌లో ప్రకటనలు, విశ్లేషణ, క్రాష్ రిపోర్టర్ లేదా ట్రాకింగ్ SDK లేవు. డెవలపర్ వ్యక్తిగత డేటా సేకరించరు, అమ్మరు లేదా పంచుకోరు.

## మీ కంప్యూటర్‌లో నిల్వ చేసిన డేటా

### సెట్టింగ్‌లు

అప్లికేషన్ సెట్టింగ్‌లు (Print Screen హాట్‌కీ, సిస్టమ్‌తో ప్రారంభం, OCR ఇంజిన్ మరియు భాషలు, హైలైటర్ రంగు, మరియు లైసెన్స్ లేదా గోప్యతా విండోలో చివరిగా ఎంచుకున్న భాష) ఈ కంప్యూటర్‌లో మాత్రమే నిల్వ అవుతాయి:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator`

### ప్రాజెక్ట్‌లు మరియు చిత్రాలు

వ్యాఖ్యానించిన ప్రాజెక్ట్‌లు మరియు ప్రివ్యూలు చిత్రాల ఫోల్డర్‌లో నిల్వ అవుతాయి:

- Windows: `%USERPROFILE%\Pictures\ScreenshotAnnotator`
- Linux: `~/Pictures/ScreenshotAnnotator`

స్క్రీన్‌షాట్‌లు, దిగుమతి చిత్రాలు మరియు వ్యాఖ్యాన వచనం ఆ స్థానిక ఫైళ్లలో ఉంటాయి (కాపీ చేస్తే క్లిప్‌బోర్డ్‌లో కూడా). యాప్ వాటిని అప్‌లోడ్ చేయదు.

### లాగ్‌లు

నిర్ధారణ లాగ్‌లు ఇక్కడ రాయవచ్చు:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator\Logs`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator/Logs`

యాప్ క్రాష్ అయితే డెస్క్‌టాప్‌లో స్థానిక లోప నివేదిక ఫైల్ రాయవచ్చు. ఆ ఫైల్ ఎక్కడికీ పంపబడదు.

ఆ విలువలు డెవలపర్‌కు అప్‌లోడ్ కావు.

మీ డేటా నిల్వ చేయడానికి డెవలపర్ సర్వర్ ఉపయోగించబడదు.

## స్క్రీన్ క్యాప్చర్ మరియు OCR

Print Screen (లేదా స్క్రీన్‌షాట్ ఆదేశం) ఉపయోగిస్తే యాప్ ప్రస్తుత స్క్రీన్‌ను క్యాప్చర్ చేస్తుంది కాబట్టి మీరు కత్తిరించి వ్యాఖ్యానించవచ్చు. క్యాప్చర్ ఈ పరికరంలో మాత్రమే జరుగుతుంది.

OCR స్థానికంగా నడుస్తుంది:

- **Windows OCR** ఈ PCలో ఆపరేటింగ్ సిస్టమ్ యొక్క `Windows.Media.Ocr` APIలను ఉపయోగిస్తుంది.
- **Tesseract** ఇన్‌స్టాల్ అయి PATHలో ఉంటే ఈ కంప్యూటర్‌లో నడుస్తుంది.

గుర్తించిన వచనం యాప్‌లో చూపబడుతుంది కాపీ లేదా సవరణ కోసం. డెవలపర్‌కు పంపబడదు.

## నెట్‌వర్క్ వినియోగం

### నవీకరణ తనిఖీ

Store కాని బిల్డ్‌లు తాజా GitHub విడుదలను అభ్యర్థించవచ్చు:

`https://api.github.com/repos/drweb86/annotator/releases/latest`

GitHub (Microsoft) సాధారణ HTTPS అభ్యర్థన (IP చిరునామా, user-agent, సమయం) స్వీకరిస్తుంది. డెవలపర్ ఆ ట్రాఫిక్ స్వీకరించరు.

Microsoft Store ఇన్‌స్టాల్‌లు ఈ తనిఖీని ఉపయోగించవు; నవీకరణలను Store అందిస్తుంది.

### మీరు తెరిచే లింక్‌లు

యాప్ సిస్టమ్ బ్రౌజర్‌లో ఈ పేజీలను తెరవవచ్చు. ఆ సైట్‌లకు వాటి స్వంత గోప్యతా విధానాలు ఉన్నాయి:

- ప్రాజెక్ట్ హోమ్‌పేజీ: [github.com/drweb86/annotator](https://github.com/drweb86/annotator)
- తాజా విడుదల: [github.com/drweb86/annotator/releases/latest](https://github.com/drweb86/annotator/releases/latest)

లైసెన్స్ యాప్ లోపల చూపబడుతుంది. వెబ్ పేజీగా తెరవబడదు.

## ఇతర స్థానిక ప్రవర్తన

Windows లేదా Linuxలో సైన్ ఇన్ చేసినప్పుడు యాప్ ప్రారంభించవచ్చు. Windowsలో స్టార్టప్ ఎంట్రీ (Store ఇన్‌స్టాల్‌లకు Microsoft Store స్టార్టప్ టాస్క్) ఉపయోగిస్తుంది. Linuxలో autostart ఎంట్రీ. అది మీ కంప్యూటర్‌లో ఈ యాప్‌ను మాత్రమే ప్రారంభిస్తుంది.

ఐచ్ఛిక ప్రపంచ Print Screen హాట్‌కీ యాప్ నడుస్తున్నప్పుడు మెమరీలో ఉంటుంది సెలెక్టర్ తెరవడానికి.

## పిల్లలు

యాప్ స్క్రీన్‌షాట్ వ్యాఖ్యాన సాధనం. 13 సంవత్సరాలలోపు పిల్లలకు లక్ష్యం కాదు.

## మూడవ పక్షాలు

GitHub పైన వలె నవీకరణ తనిఖీ మరియు మీరు తెరిచే పేజీలను ప్రాసెస్ చేస్తుంది. Microsoft Store Store ఇన్‌స్టాల్‌లు మరియు నవీకరణలను ప్రాసెస్ చేస్తుంది. Windows OCRను ఆపరేటింగ్ సిస్టమ్ అందిస్తుంది. డెవలపర్ ఆ ట్రాఫిక్ స్వీకరించరు.
