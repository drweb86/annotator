# ಗೌಪ್ಯತೆ ನೀತಿ

ಕೊನೆಯ ನವೀಕರಣ: 20 ಸೆಪ್ಟೆಂಬರ್ 2026

**Screenshot Annotator** by Siarhei Kuchuk

ಅಪ್ಲಿಕೇಶನ್ ಹೆಸರು: Screenshot Annotator
ಡೆವಲಪರ್ ಹೆಸರು: Siarhei Kuchuk

ಸಾಫ್ಟ್‌ವೇರ್ ಈ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಸ್ಕ್ರೀನ್‌ಶಾಟ್ ತೆಗೆಯುತ್ತದೆ, ಟಿಪ್ಪಣಿ ಮಾಡಲು ಅನುಮತಿಸುತ್ತದೆ ಮತ್ತು OCR ನಿಂದ ಆಯ್ದ ಪ್ರದೇಶದ ಪಠ್ಯವನ್ನು ಓದಬಹುದು. ಇದು ಕ್ಲೌಡ್ ಖಾತೆಗಳನ್ನು ರಚಿಸುವುದಿಲ್ಲ. ಡೆವಲಪರ್ ನಿಮ್ಮ ಸ್ಕ್ರೀನ್‌ಶಾಟ್, ಯೋಜನೆಗಳು ಅಥವಾ ಬಳಕೆ ಡೇಟಾ ಸ್ವೀಕರಿಸುವ ಸರ್ವರ್ ನಡೆಸುವುದಿಲ್ಲ.

## ಡೆವಲಪರ್ ಸಂಗ್ರಹಿಸದ ಡೇಟಾ

ಅಪ್ಲಿಕೇಶನ್‌ನಲ್ಲಿ ಜಾಹೀರಾತು, ವಿಶ್ಲೇಷಣೆ, ಕ್ರ್ಯಾಶ್ ವರದಿಗಾರ ಅಥವಾ ಟ್ರ್ಯಾಕಿಂಗ್ SDK ಇಲ್ಲ. ಡೆವಲಪರ್ ವೈಯಕ್ತಿಕ ಡೇಟಾ ಸಂಗ್ರಹಿಸುವುದಿಲ್ಲ, ಮಾರುವುದಿಲ್ಲ ಅಥವಾ ಹಂಚಿಕೊಳ್ಳುವುದಿಲ್ಲ.

## ನಿಮ್ಮ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಸಂಗ್ರಹಿಸಿದ ಡೇಟಾ

### ಸೆಟ್ಟಿಂಗ್‌ಗಳು

ಅಪ್ಲಿಕೇಶನ್ ಸೆಟ್ಟಿಂಗ್‌ಗಳು (Print Screen ಹಾಟ್‌ಕೀ, ಸಿಸ್ಟಂನೊಂದಿಗೆ ಪ್ರಾರಂಭ, OCR ಎಂಜಿನ್ ಮತ್ತು ಭಾಷೆಗಳು, ಹೈಲೈಟರ್ ಬಣ್ಣ, ಮತ್ತು ಪರವಾನಗಿ ಅಥವಾ ಗೌಪ್ಯತೆ ವಿಂಡೋದಲ್ಲಿ ಕೊನೆಯ ಆಯ್ಕೆ ಭಾಷೆ) ಈ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಮಾತ್ರ ಸಂಗ್ರಹಿಸಲಾಗುತ್ತದೆ:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator`

### ಯೋಜನೆಗಳು ಮತ್ತು ಚಿತ್ರಗಳು

ಟಿಪ್ಪಣಿ ಮಾಡಿದ ಯೋಜನೆಗಳು ಮತ್ತು ಪೂರ್ವವೀಕ್ಷಣೆಗಳು ಚಿತ್ರಗಳ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ ಸಂಗ್ರಹಿಸಲಾಗುತ್ತದೆ:

- Windows: `%USERPROFILE%\Pictures\ScreenshotAnnotator`
- Linux: `~/Pictures/ScreenshotAnnotator`

ಸ್ಕ್ರೀನ್‌ಶಾಟ್‌ಗಳು, ಆಮದು ಚಿತ್ರಗಳು ಮತ್ತು ಟಿಪ್ಪಣಿ ಪಠ್ಯ ಆ ಸ್ಥಳೀಯ ಫೈಲ್‌ಗಳಲ್ಲಿ ಉಳಿಯುತ್ತವೆ (ನಕಲಿಸಿದರೆ ಕ್ಲಿಪ್‌ಬೋರ್ಡ್‌ನಲ್ಲಿಯೂ). ಅಪ್ಲಿಕೇಶನ್ ಅವುಗಳನ್ನು ಅಪ್‌ಲೋಡ್ ಮಾಡುವುದಿಲ್ಲ.

### ಲಾಗ್‌ಗಳು

ರೋಗನಿರ್ಣಯ ಲಾಗ್‌ಗಳನ್ನು ಇಲ್ಲಿ ಬರೆಯಬಹುದು:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator\Logs`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator/Logs`

ಅಪ್ಲಿಕೇಶನ್ ಕ್ರ್ಯಾಶ್ ಆದರೆ ಡೆಸ್ಕ್‌ಟಾಪ್‌ನಲ್ಲಿ ಸ್ಥಳೀಯ ದೋಷ ವರದಿ ಫೈಲ್ ಬರೆಯಬಹುದು. ಆ ಫೈಲ್ ಎಲ್ಲಿಗೂ ಕಳುಹಿಸಲಾಗುವುದಿಲ್ಲ.

ಆ ಮೌಲ್ಯಗಳನ್ನು ಡೆವಲಪರ್‌ಗೆ ಅಪ್‌ಲೋಡ್ ಮಾಡಲಾಗುವುದಿಲ್ಲ.

ನಿಮ್ಮ ಡೇಟಾ ಸಂಗ್ರಹಿಸಲು ಡೆವಲಪರ್ ಸರ್ವರ್ ಬಳಸಲಾಗುವುದಿಲ್ಲ.

## ಸ್ಕ್ರೀನ್ ಸೆರೆಹಿಡಿಯುವಿಕೆ ಮತ್ತು OCR

Print Screen (ಅಥವಾ ಸ್ಕ್ರೀನ್‌ಶಾಟ್ ಆಜ್ಞೆ) ಬಳಸಿದಾಗ ಅಪ್ಲಿಕೇಶನ್ ಪ್ರಸ್ತುತ ಸ್ಕ್ರೀನ್ ಸೆರೆಹಿಡಿಯುತ್ತದೆ ಇದರಿಂದ ನೀವು ಕತ್ತರಿಸಿ ಟಿಪ್ಪಣಿ ಮಾಡಬಹುದು. ಸೆರೆಹಿಡಿಯುವಿಕೆ ಈ ಸಾಧನದಲ್ಲಿ ಮಾತ್ರ ನಡೆಯುತ್ತದೆ.

OCR ಸ್ಥಳೀಯವಾಗಿ ಚಲಿಸುತ್ತದೆ:

- **Windows OCR** ಈ PC ಯಲ್ಲಿ ಆಪರೇಟಿಂಗ್ ಸಿಸ್ಟಂನ `Windows.Media.Ocr` API ಗಳನ್ನು ಬಳಸುತ್ತದೆ.
- **Tesseract** ಸ್ಥಾಪಿಸಿದ್ದು PATH ನಲ್ಲಿದ್ದರೆ ಈ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಚಲಿಸುತ್ತದೆ.

ಗುರುತಿಸಿದ ಪಠ್ಯವನ್ನು ಅಪ್ಲಿಕೇಶನ್‌ನಲ್ಲಿ ತೋರಿಸಲಾಗುತ್ತದೆ ನಕಲಿಸಲು ಅಥವಾ ಸಂಪಾದಿಸಲು. ಡೆವಲಪರ್‌ಗೆ ಕಳುಹಿಸಲಾಗುವುದಿಲ್ಲ.

## ನೆಟ್‌ವರ್ಕ್ ಬಳಕೆ

### ನವೀಕರಣ ಪರಿಶೀಲನೆ

Store ಅಲ್ಲದ ಬಿಲ್ಡ್‌ಗಳು ಇತ್ತೀಚಿನ GitHub ಬಿಡುಗಡೆ ವಿನಂತಿಸಬಹುದು:

`https://api.github.com/repos/drweb86/annotator/releases/latest`

GitHub (Microsoft) ಸಾಮಾನ್ಯ HTTPS ವಿನಂತಿ (IP ವಿಳಾಸ, user-agent, ಸಮಯ) ಸ್ವೀಕರಿಸುತ್ತದೆ. ಡೆವಲಪರ್ ಆ ಟ್ರಾಫಿಕ್ ಸ್ವೀಕರಿಸುವುದಿಲ್ಲ.

Microsoft Store ಸ್ಥಾಪನೆಗಳು ಈ ಪರಿಶೀಲನೆ ಬಳಸುವುದಿಲ್ಲ; ನವೀಕರಣಗಳನ್ನು Store ತಲುಪಿಸುತ್ತದೆ.

### ನೀವು ತೆರೆಯುವ ಲಿಂಕ್‌ಗಳು

ಅಪ್ಲಿಕೇಶನ್ ಸಿಸ್ಟಂ ಬ್ರೌಸರ್‌ನಲ್ಲಿ ಈ ಪುಟಗಳನ್ನು ತೆರೆಯಬಹುದು. ಆ ಸೈಟ್‌ಗಳಿಗೆ ಸ್ವಂತ ಗೌಪ್ಯತೆ ನೀತಿ ಇದೆ:

- ಯೋಜನೆ ಮುಖಪುಟ: [github.com/drweb86/annotator](https://github.com/drweb86/annotator)
- ಇತ್ತೀಚಿನ ಬಿಡುಗಡೆ: [github.com/drweb86/annotator/releases/latest](https://github.com/drweb86/annotator/releases/latest)

ಪರವಾನಗಿ ಅಪ್ಲಿಕೇಶನ್ ಒಳಗೆ ತೋರಿಸಲಾಗುತ್ತದೆ. ವೆಬ್ ಪುಟವಾಗಿ ತೆರೆಯಲಾಗುವುದಿಲ್ಲ.

## ಇತರ ಸ್ಥಳೀಯ ವರ್ತನೆ

Windows ಅಥವಾ Linux ಗೆ ಸೈನ್ ಇನ್ ಮಾಡಿದಾಗ ಅಪ್ಲಿಕೇಶನ್ ಪ್ರಾರಂಭಿಸಬಹುದು. Windows ನಲ್ಲಿ ಸ್ಟಾರ್ಟಪ್ ನಮೂದು (Store ಸ್ಥಾಪನೆಗಳಿಗೆ Microsoft Store ಸ್ಟಾರ್ಟಪ್ ಕಾರ್ಯ) ಬಳಸುತ್ತದೆ. Linux ನಲ್ಲಿ autostart ನಮೂದು. ಅದು ನಿಮ್ಮ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಈ ಅಪ್ಲಿಕೇಶನ್ ಮಾತ್ರ ಪ್ರಾರಂಭಿಸುತ್ತದೆ.

ಐಚ್ಛಿಕ ಜಾಗತಿಕ Print Screen ಹಾಟ್‌ಕೀ ಅಪ್ಲಿಕೇಶನ್ ಚಾಲನೆಯಲ್ಲಿರುವಾಗ ಮೆಮೊರಿಯಲ್ಲಿ ಉಳಿಯುತ್ತದೆ ಆಯ್ಕೆಕಾರ ತೆರೆಯಲು.
