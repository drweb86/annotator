# Πολιτική απορρήτου

Τελευταία ενημέρωση: 20 Σεπτεμβρίου 2026

**Screenshot Annotator** by Siarhei Kuchuk

Όνομα εφαρμογής: Screenshot Annotator
Όνομα προγραμματιστή: Siarhei Kuchuk

Το λογισμικό συλλαμβάνει στιγμιότυπα σε αυτόν τον υπολογιστή, επιτρέπει σχολιασμό και μπορεί να διαβάσει κείμενο από επιλεγμένη περιοχή με OCR. Δεν δημιουργεί λογαριασμούς cloud. Ο προγραμματιστής δεν λειτουργεί διακομιστή που λαμβάνει τα στιγμιότυπα, τα έργα ή τα δεδομένα χρήσης σας.

## Δεδομένα που δεν συλλέγει ο προγραμματιστής

Η εφαρμογή δεν περιλαμβάνει διαφημίσεις, αναλυτικά, αναφορές σφαλμάτων ή SDK παρακολούθησης. Ο προγραμματιστής δεν συλλέγει, δεν πουλάει και δεν κοινοποιεί προσωπικά δεδομένα.

## Δεδομένα που αποθηκεύονται στον υπολογιστή σας

### Ρυθμίσεις

Οι ρυθμίσεις της εφαρμογής (συντόμευση Print Screen, εκκίνηση με το σύστημα, μηχανή OCR και γλώσσες, χρώμα επισήμανσης και η τελευταία γλώσσα στα παράθυρα Άδεια ή Απόρρητο) αποθηκεύονται μόνο σε αυτόν τον υπολογιστή:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator`

### Έργα και εικόνες

Τα σχολιασμένα έργα και οι προεπισκοπήσεις αποθηκεύονται στον φάκελο Εικόνες:

- Windows: `%USERPROFILE%\Pictures\ScreenshotAnnotator`
- Linux: `~/Pictures/ScreenshotAnnotator`

Τα στιγμιότυπα, οι εισαγόμενες εικόνες και το κείμενο σχολίων μένουν σε αυτά τα τοπικά αρχεία (ή στο πρόχειρο αν τα αντιγράψετε). Η εφαρμογή δεν τα μεταφορτώνει.

### Αρχεία καταγραφής

Διαγνωστικά αρχεία καταγραφής μπορεί να γράφονται σε:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator\Logs`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator/Logs`

Αν η εφαρμογή διακοπεί απότομα, μπορεί να γράψει τοπικό αρχείο αναφοράς σφάλματος στην Επιφάνεια εργασίας. Το αρχείο δεν αποστέλλεται πουθενά.

Αυτές οι τιμές δεν μεταφορτώνονται στον προγραμματιστή.

Δεν χρησιμοποιείται διακομιστής του προγραμματιστή για αποθήκευση των δεδομένων σας.

## Σύλληψη οθόνης και OCR

Όταν χρησιμοποιείτε Print Screen (ή την εντολή στιγμιότυπου), η εφαρμογή συλλαμβάνει την τρέχουσα οθόνη ώστε να την περικόψετε και να τη σχολιάσετε. Η σύλληψη γίνεται μόνο σε αυτή τη συσκευή.

Το OCR εκτελείται τοπικά:

- Το **Windows OCR** χρησιμοποιεί τα API `Windows.Media.Ocr` του λειτουργικού σε αυτόν τον υπολογιστή.
- Το **Tesseract** εκτελείται σε αυτόν τον υπολογιστή αν είναι εγκατεστημένο και στο PATH.

Το αναγνωρισμένο κείμενο εμφανίζεται στην εφαρμογή για αντιγραφή ή επεξεργασία. Δεν αποστέλλεται στον προγραμματιστή.

## Χρήση δικτύου

### Έλεγχος ενημερώσεων

Οι εκδόσεις εκτός Store μπορεί να ζητήσουν την τελευταία έκδοση GitHub:

`https://api.github.com/repos/drweb86/annotator/releases/latest`

Το GitHub (Microsoft) λαμβάνει κανονικό αίτημα HTTPS (διεύθυνση IP, user-agent, ώρα). Ο προγραμματιστής δεν λαμβάνει αυτή την κίνηση.

Οι εγκαταστάσεις από το Microsoft Store δεν χρησιμοποιούν αυτόν τον έλεγχο· το Store παρέχει ενημερώσεις.

### Σύνδεσμοι που ανοίγετε

Η εφαρμογή μπορεί να ανοίξει αυτές τις σελίδες στο πρόγραμμα περιήγησης του συστήματος. Οι ιστότοποι έχουν δικές τους πολιτικές απορρήτου:

- Αρχική σελίδα έργου: [github.com/drweb86/annotator](https://github.com/drweb86/annotator)
- Τελευταία έκδοση: [github.com/drweb86/annotator/releases/latest](https://github.com/drweb86/annotator/releases/latest)

Η άδεια εμφανίζεται μέσα στην εφαρμογή. Δεν ανοίγει ως ιστοσελίδα.

## Άλλη τοπική συμπεριφορά

Μπορείτε να ξεκινάτε την εφαρμογή κατά την είσοδο σε Windows ή Linux. Στα Windows χρησιμοποιείται καταχώριση εκκίνησης (ή εργασία εκκίνησης Microsoft Store για εγκαταστάσεις Store). Στα Linux καταχώριση autostart. Αυτό ξεκινά μόνο αυτή την εφαρμογή στον υπολογιστή σας.

Η προαιρετική καθολική συντόμευση Print Screen παραμένει στη μνήμη όσο εκτελείται η εφαρμογή ώστε να ανοίξει ο επιλογέας.

## Παιδιά

Η εφαρμογή είναι εργαλείο σχολιασμού στιγμιότυπων. Δεν απευθύνεται σε παιδιά κάτω των 13 ετών.

## Τρίτοι

Το GitHub επεξεργάζεται τον έλεγχο ενημερώσεων και τις σελίδες που ανοίγετε, όπως παραπάνω. Το Microsoft Store επεξεργάζεται εγκαταστάσεις και ενημερώσεις Store. Το Windows OCR παρέχεται από το λειτουργικό σύστημα. Ο προγραμματιστής δεν λαμβάνει αυτή την κίνηση.
