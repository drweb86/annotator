# රහස්‍යතා ප්‍රතිපත්තිය

අවසන් යාවත්කාලීනය: 2026 සැප්තැම්බර් 20

**Screenshot Annotator** by Siarhei Kuchuk

යෙදුම් නම: Screenshot Annotator
සංවර්ධක නම: Siarhei Kuchuk

මෘදුකාංගය මෙම පරිගණකයේ තිර රූප ගනී, සටහන් යෙදීමට ඉඩ දෙයි, සහ OCR මගින් තෝරාගත් ප්‍රදේශයෙන් පෙළ කියවිය හැක. එය වලාකුළු ගිණුම් නිර්මාණය නොකරයි. සංවර්ධකයා ඔබේ තිර රූප, ව්‍යාපෘති හෝ භාවිත දත්ත ලබා ගන්නා සර්වරයක් පවත්වන්නේ නැත.

## සංවර්ධකයා එකතු නොකරන දත්ත

යෙදුමේ දැන්වීම්, විශ්ලේෂණ, බිඳවැටීම් වාර්තාකරු හෝ ලුහුබැඳීමේ SDK නැත. සංවර්ධකයා පුද්ගලික දත්ත එකතු, විකුණුම් හෝ බෙදාගැනීම් නොකරයි.

## ඔබේ පරිගණකයේ ගබඩා කරන දත්ත

### සැකසුම්

යෙදුම් සැකසුම් (Print Screen හොට්කී, පද්ධතිය සමඟ ආරම්භය, OCR එන්ජිම සහ භාෂා, හයිලයිටර් වර්ණය, සහ බලපත්‍ර හෝ රහස්‍යතා කවුළුවේ අවසන් තෝරාගත් භාෂාව) මෙම පරිගණකයේ පමණක් ගබඩා වේ:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator`

### ව්‍යාපෘති සහ රූප

සටහන් යෙදූ ව්‍යාපෘති සහ පෙරදසුන් රූප ෆෝල්ඩරයේ ගබඩා වේ:

- Windows: `%USERPROFILE%\Pictures\ScreenshotAnnotator`
- Linux: `~/Pictures/ScreenshotAnnotator`

තිර රූප, ආනයනිත රූප සහ සටහන් පෙළ එම දේශීය ගොනුවල රැඳේ (පිටපත් කළහොත් ක්ලිප්බෝඩ්හිද). යෙදුම ඒවා උඩුගත නොකරයි.

### ලොග්

රෝග විනිශ්චය ලොග් මෙහි ලිවිය හැක:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator\Logs`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator/Logs`

යෙදුම බිඳ වැටුණහොත් ඩෙස්ක්ටොප්හි දේශීය දෝෂ වාර්තා ගොනුවක් ලිවිය හැක. එම ගොනුව කිසිතැනකට යවන්නේ නැත.

එම අගයන් සංවර්ධකයාට උඩුගත නොවේ.

ඔබේ දත්ත ගබඩා කිරීමට සංවර්ධක සර්වරයක් භාවිතා නොවේ.

## තිර ග්‍රහණය සහ OCR

Print Screen (හෝ තිර රූප විධානය) භාවිතා කළ විට යෙදුම වත්මන් තිරය ග්‍රහණය කරයි ඔබට කපා සටහන් යෙදීමට. ග්‍රහණය මෙම උපාංගයේ පමණක් සිදු වේ.

OCR දේශීයව ධාවනය වේ:

- **Windows OCR** මෙම PC හි මෙහෙයුම් පද්ධතියේ `Windows.Media.Ocr` API භාවිතා කරයි.
- **Tesseract** ස්ථාපනය කර PATH හි තිබේ නම් මෙම පරිගණකයේ ධාවනය වේ.

හඳුනාගත් පෙළ යෙදුමේ පෙන්වයි පිටපත් හෝ සංස්කරණයට. සංවර්ධකයාට යවන්නේ නැත.

## ජාල භාවිතය

### යාවත්කාලීන පරීක්ෂාව

Store නොවන ගොඩනැගීම් නවතම GitHub නිකුතුව ඉල්ලිය හැක:

`https://api.github.com/repos/drweb86/annotator/releases/latest`

GitHub (Microsoft) සාමාන්‍ය HTTPS ඉල්ලීමක් (IP ලිපිනය, user-agent, වේලාව) ලබා ගනී. සංවර්ධකයා එම ගමනාගමනය ලබා නොගනී.

Microsoft Store ස්ථාපනයන් මෙම පරීක්ෂාව භාවිතා නොකරයි; යාවත්කාලීන Store ලබා දෙයි.

### ඔබ විවෘත කරන සබැඳි

යෙදුම පද්ධති බ්‍රව්සරයේ මෙම පිටු විවෘත කළ හැක. එම අඩවිවලට තමන්ගේ රහස්‍යතා ප්‍රතිපත්ති ඇත:

- ව්‍යාපෘති මුල් පිටුව: [github.com/drweb86/annotator](https://github.com/drweb86/annotator)
- නවතම නිකුතුව: [github.com/drweb86/annotator/releases/latest](https://github.com/drweb86/annotator/releases/latest)

බලපත්‍රය යෙදුම තුළ පෙන්වයි. වෙබ් පිටුවක් ලෙස විවෘත නොකෙරේ.

## වෙනත් දේශීය හැසිරීම

Windows හෝ Linux වෙත පිවිසෙන විට යෙදුම ආරම්භ කළ හැක. Windows හි ආරම්භක ඇතුළත් කිරීමක් (Store ස්ථාපනයන් සඳහා Microsoft Store ආරම්භක කාර්යය) භාවිතා කරයි. Linux හි autostart ඇතුළත් කිරීමක්. එය ඔබේ පරිගණකයේ මෙම යෙදුම පමණක් දියත් කරයි.

විකල්ප ගෝලීය Print Screen හොට්කී යෙදුම ධාවනය වන අතරතුර මතකයේ රැඳේ තෝරන්නා විවෘත කිරීමට.
