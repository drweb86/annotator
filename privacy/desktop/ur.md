# رازداری کی پالیسی

آخری تازہ کاری: 20 ستمبر 2026

**Screenshot Annotator** by Siarhei Kuchuk

ایپلیکیشن کا نام: Screenshot Annotator
ڈویلپر کا نام: Siarhei Kuchuk

سافٹ ویئر اس کمپیوٹر پر اسکرین شاٹ لیتا ہے، تشریح کرنے دیتا ہے، اور OCR سے منتخب علاقے کا متن پڑھ سکتا ہے۔ کلاؤڈ اکاؤنٹ نہیں بناتا۔ ڈویلپر ایسا سرور نہیں چلاتا جو آپ کے اسکرین شاٹ، منصوبے یا استعمال کا ڈیٹا وصول کرے۔

## وہ ڈیٹا جو ڈویلپر جمع نہیں کرتا

ایپ میں اشتہارات، تجزیات، کریش رپورٹر یا ٹریکنگ SDK نہیں ہے۔ ڈویلپر ذاتی ڈیٹا جمع، فروخت یا شیئر نہیں کرتا۔

## آپ کے کمپیوٹر پر محفوظ ڈیٹا

### ترتیبات

ایپلیکیشن کی ترتیبات (Print Screen ہاٹ کی، سسٹم کے ساتھ آغاز، OCR انجن اور زبانیں، ہائی لائٹر رنگ، اور لائسنس یا رازداری ونڈو میں آخری منتخب زبان) صرف اس کمپیوٹر پر محفوظ ہوتی ہیں:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator`

### منصوبے اور تصاویر

تشریح شدہ منصوبے اور پیش نظارے تصاویر فولڈر میں محفوظ ہوتے ہیں:

- Windows: `%USERPROFILE%\Pictures\ScreenshotAnnotator`
- Linux: `~/Pictures/ScreenshotAnnotator`

اسکرین شاٹ، درآمد شدہ تصاویر اور تشریح کا متن ان مقامی فائلوں میں رہتا ہے (کاپی کریں تو کلپ بورڈ پر بھی)۔ ایپ انہیں اپ لوڈ نہیں کرتی۔

### لاگز

تشخیصی لاگز یہاں لکھے جا سکتے ہیں:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator\Logs`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator/Logs`

اگر ایپ کریش ہو تو ڈیسک ٹاپ پر مقامی غلطی کی رپورٹ فائل لکھ سکتی ہے۔ وہ فائل کہیں نہیں بھیجی جاتی۔

وہ قدریں ڈویلپر کو اپ لوڈ نہیں ہوتیں۔

آپ کا ڈیٹا محفوظ کرنے کے لیے ڈویلپر سرور استعمال نہیں ہوتا۔

## اسکرین کیپچر اور OCR

جب آپ Print Screen (یا اسکرین شاٹ کمانڈ) استعمال کرتے ہیں تو ایپ موجودہ اسکرین کیپچر کرتی ہے تاکہ آپ کاٹ کر تشریح کر سکیں۔ کیپچر صرف اس ڈیوائس پر ہوتا ہے۔

OCR مقامی طور پر چلتا ہے:

- **Windows OCR** اس PC پر آپریٹنگ سسٹم کے `Windows.Media.Ocr` API استعمال کرتا ہے۔
- **Tesseract** اگر انسٹال ہو اور PATH میں ہو تو اس کمپیوٹر پر چلتا ہے۔

شناخت شدہ متن ایپ میں دکھایا جاتا ہے تاکہ کاپی یا ترمیم کر سکیں۔ ڈویلپر کو نہیں بھیجا جاتا۔

## نیٹ ورک کا استعمال

### اپ ڈیٹ چیک

Store سے باہر بلڈ تازہ ترین GitHub ریلیز مانگ سکتے ہیں:

`https://api.github.com/repos/drweb86/annotator/releases/latest`

GitHub (Microsoft) عام HTTPS درخواست (IP پتہ، user-agent، وقت) وصول کرتا ہے۔ ڈویلپر وہ ٹریفک وصول نہیں کرتا۔

Microsoft Store انسٹال یہ چیک استعمال نہیں کرتے؛ اپ ڈیٹ Store پہنچاتا ہے۔

### وہ لنکس جو آپ کھولتے ہیں

ایپ سسٹم براؤزر میں یہ صفحات کھول سکتی ہے۔ ان سائٹس کی اپنی رازداری کی پالیسیاں ہیں:

- منصوبے کا ہوم پیج: [github.com/drweb86/annotator](https://github.com/drweb86/annotator)
- تازہ ترین ریلیز: [github.com/drweb86/annotator/releases/latest](https://github.com/drweb86/annotator/releases/latest)

لائسنس ایپ کے اندر دکھایا جاتا ہے۔ ویب صفحہ کے طور پر نہیں کھولا جاتا۔

## دیگر مقامی رویہ

Windows یا Linux میں سائن ان کرتے وقت ایپ شروع کر سکتے ہیں۔ Windows پر اسٹارٹ اپ انٹری (Store انسٹال کے لیے Microsoft Store اسٹارٹ اپ ٹاسک) استعمال ہوتی ہے۔ Linux پر autostart انٹری۔ وہ صرف یہ ایپ آپ کے کمپیوٹر پر شروع کرتی ہے۔

اختیاری عالمی Print Screen ہاٹ کی ایپ چلتے ہوئے میموری میں رہتی ہے تاکہ سلیکٹر کھل سکے۔
