# Ìlànà ìkọ̀kọ̀

Ìmúdójúìwọ̀n kẹ́yìn: 20 Oṣù Kẹ̀sán 2026

**Screenshot Annotator** by Siarhei Kuchuk

Orúkọ ìṣàfilọ́lẹ̀: Screenshot Annotator
Orúkọ olùgbéejáde: Siarhei Kuchuk

Sọ́fíwẹ̀ yìí ń ya àwòrán ojú ìwòrán lórí kọ̀mpútà yìí, ó jẹ́ kí o ṣe àkọsílẹ̀, ó sì lè ka ọ̀rọ̀ láti àgbègbè tí o yàn pẹ̀lú OCR. Kò ṣẹ̀dá àkántì ìkùukùu. Olùgbéejáde kò ṣiṣẹ́ sáfà tó ń gba àwòrán, iṣẹ́ tàbí dátà lílo rẹ.

## Dátà tí olùgbéejáde kò gba

Àpù náà kò ní ìpolówó, ìtúpalẹ̀, olùròyìn ìbàjẹ́ tàbí SDK ìtẹ̀lé. Olùgbéejáde kò gba, tà, tàbí pín dátà ti ara ẹni.

## Dátà tí a fi pamọ́ sórí kọ̀mpútà rẹ

### Àwọn ètò

Àwọn ètò ìṣàfilọ́lẹ̀ (bọtìnì Print Screen, bẹ̀rẹ̀ pẹ̀lú ètò, ẹ̀rọ OCR àti èdè, àwọ̀ amí, àti èdè tí a yàn kẹ́yìn nínú fèrèsé Ìwé-àṣẹ tàbí Ìkọ̀kọ̀) ni a fi pamọ́ sórí kọ̀mpútà yìí nìkan:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator`

### Àwọn iṣẹ́ àti àwòrán

Àwọn iṣẹ́ tí a ṣàkọsílẹ̀ àti àwòrán àkọ́kọ́ ni a fi pamọ́ sínú fódà Àwòrán:

- Windows: `%USERPROFILE%\Pictures\ScreenshotAnnotator`
- Linux: `~/Pictures/ScreenshotAnnotator`

Àwòrán ojú ìwòrán, àwòrán tí a kó wọlé, àti ọ̀rọ̀ àkọsílẹ̀ dúró nínú àwọn fáìlì agbègbè yẹn (tàbí clipboard tí o bá ṣe ẹ̀dà). Àpù náà kò gbé wọn sókè.

### Àwọn àkọsílẹ̀

Àwọn àkọsílẹ̀ ìwádìí lè jẹ́ kíkọ sí:

- Windows: `%AppData%\SiarheiKuchuk.ScreenshotAnnotator\Logs`
- Linux: `~/.config/SiarheiKuchuk.ScreenshotAnnotator/Logs`

Tí àpù náà bá ṣubú, ó lè kọ fáìlì ìròyìn àṣìṣe agbègbè sórí Desktop. A kò fi fáìlì yẹn ránṣẹ́ sí ibikíbi.

A kò gbé àwọn iye yẹn sókè sí olùgbéejáde.

A kò lo sáfà olùgbéejáde láti fi dátà rẹ pamọ́.

## Yíyà ojú ìwòrán àti OCR

Nígbà tí o bá lo Print Screen (tàbí àṣẹ screenshot), àpù náà ya ojú ìwòrán lọ́wọ́lọ́wọ́ kí o lè gé àti ṣàkọsílẹ̀. Yíyà ṣẹlẹ̀ lórí ẹ̀rọ yìí nìkan.

OCR ń ṣiṣẹ́ ní agbègbè:

- **Windows OCR** ń lo API `Windows.Media.Ocr` ètò iṣẹ́ lórí PC yìí.
- **Tesseract** ń ṣiṣẹ́ lórí kọ̀mpútà yìí tí o bá fi sílẹ̀ tí ó sì wà nínú PATH.

Ọ̀rọ̀ tí a mọ̀ ni a fi hàn nínú àpù kí o lè ṣe ẹ̀dà tàbí ṣàtúnṣe. A kò fi ránṣẹ́ sí olùgbéejáde.

## Lílo nẹ́tíwọ́kì

### Ìyẹ̀wò ìmúdójúìwọ̀n

Àwọn ìkọ́ tí kì í ṣe Store lè béèrè ìtújáde GitHub tuntun jùlọ:

`https://api.github.com/repos/drweb86/annotator/releases/latest`

GitHub (Microsoft) ń gba ìbéèrè HTTPS deede (àdírẹ́sì IP, user-agent, àkókò). Olùgbéejáde kò gba ìrìnàjò yẹn.

Àwọn ìfi sílẹ̀ Microsoft Store kò lo ìyẹ̀wò yìí; Store ni ó ń fi ìmúdójúìwọ̀n ránṣẹ́.

### Àwọn ìjápọ̀ tí o ṣí

Àpù náà lè ṣí àwọn ojú-ewé wọ̀nyí nínú ìṣàwárí ètò. Àwọn ibi wọ̀nyẹn ní ìlànà ìkọ̀kọ̀ tiwọn:

- Ojú-ewé ile iṣẹ́: [github.com/drweb86/annotator](https://github.com/drweb86/annotator)
- Ìtújáde tuntun jùlọ: [github.com/drweb86/annotator/releases/latest](https://github.com/drweb86/annotator/releases/latest)

A fi ìwé-àṣẹ hàn nínú àpù. A kò ṣí i gẹ́gẹ́ bí ojú-ewé wẹ́ẹ̀bù.

## Ìwà agbègbè mìíràn

O lè bẹ̀rẹ̀ àpù nígbà tí o bá wọlé sí Windows tàbí Linux. Lórí Windows ó ń lo ìforúkọsílẹ̀ ìbẹ̀rẹ̀ (tàbí iṣẹ́ ìbẹ̀rẹ̀ Microsoft Store fún ìfi sílẹ̀ Store). Lórí Linux ìforúkọsílẹ̀ autostart. Ìyẹn ń ṣí àpù yìí nìkan lórí kọ̀mpútà rẹ.

Bọtìnì Print Screen àgbáyé àṣàyàn dúró nínú ìrántí nígbà tí àpù ń ṣiṣẹ́ kí ó lè ṣí olùyàn.

## Àwọn ọmọdé

Àpù náà jẹ́ irinṣẹ́ àkọsílẹ̀ àwòrán ojú ìwòrán. Kò ṣe fún àwọn ọmọdé tí kò tíì pé ọdún 13.

## Àwọn ẹni kẹta

GitHub ń ṣe ìyẹ̀wò ìmúdójúìwọ̀n àti àwọn ojú-ewé tí o ṣí, bí o ṣe wà lókè. Microsoft Store ń ṣe àwọn ìfi sílẹ̀ àti ìmúdójúìwọ̀n Store. Windows OCR ni ètò iṣẹ́ ń pèsè. Olùgbéejáde kò gba ìrìnàjò yẹn.

## Àwọn ìyípadà
